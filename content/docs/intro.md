## Как работает макетная плата (breadboard)

Макетная плата — это ваш холст для создания электрических схем без пайки. Выглядит как пластмасска с дырками:

```
    a b c d e   f g h i j
    ┌─────────────────────┐
  1 │ ● ● ● ● ●   ● ● ● ● │
  2 │ ● ● ● ● ●   ● ● ● ● │
  3 │ ● ● ● ● ●   ● ● ● ● │
    └─────────────────────┘

═══════════════════════════  ← Шины питания (+ и -)
```

**Важные правила:**
- **Горизонтальные ряды (1, 2, 3...):** Отверстия в одном ряду соединены между собой (но только в пределах одной половины — до центральной канавки)
- **Вертикальные шины (по краям):** Длинные полосы для питания (+) и земли (-)
- **Центральная канавка:** Разделяет левую и правую стороны — они НЕ соединены

**Как пользоваться:**
1. Воткните компонент так, чтобы его ножки были в разных рядах
2. Соедините компоненты проводами через отверстия
3. Подключите питание к шинам + и -

## Базовые компоненты

### 1. Светодиод (LED)

Светодиод — это диод, который светится при прохождении тока.

```
        Анод (+)
          │
          ▼
         ╱│╲    ← Светодиод
        ╱ │ ╲
       ────────
          │
        Катод (-)
```

**Полярность (ОЧЕНЬ ВАЖНО!):**
- **Длинная ножка** = Анод (+) = подключать к плюсу
- **Короткая ножка** = Катод (-) = подключать к минусу
- Внутри: большой кристалл = катод

**Что нужно знать:**
- Светодиод **обязательно** включать через резистор, иначе он скорее всего сгорит
- Падение напряжения: ~2V (красный), ~3V (синий, белый)
- Рабочий ток: обычно 10-20 мА

**Почему нужен резистор:**
Светодиод потребляет столько тока, сколько ему дадут, и может сгореть. Резистор ограничивает ток.

---

### 2. Резистор

Резистор ограничивает ток в цепи.

```
    ──[ R ]──

```

иногда ещё такими зубчиками обозначают, но мы будем изображать квадратики
```
    ──/\/\/──

```

**Полярности НЕТ** — можно включать любой стороной.

**Номиналы и цветовая маркировка:**
Цветные полоски показывают сопротивление.

Примеры:
- **220Ω** (красный-красный-коричневый) — для светодиодов
- **1kΩ** (коричневый-чёрный-красный) — общего назначения
- **10kΩ** (коричневый-чёрный-оранжевый) — для транзисторов
- **100kΩ** (коричневый-чёрный-жёлтый) — для высокого сопротивления

**Закон Ома:**
```
V = I × R

V — напряжение (вольты)
I — ток (амперы)
R — сопротивление (омы)
```

**Пример расчёта резистора для светодиода:**
- Питание: 9V
- Падение напряжения на светодиоде: 2V
- Желаемый ток: 15 мА = 0.015 А

R = (9V - 2V) / 0.015A = 467Ω → берём ближайший стандартный 470Ω или 220Ω

Обычно падение напряжения и желаемый ток можно найти в описании компонента, но вообще мы ставим сотку что у вас они _практически_ всегда будут 2V и 0.015 A

---

### 3. Конденсатор

Конденсатор — это "накопитель" электрического заряда. Обычно он нужен там где нужно получить какой-то период времени или частоту колебаний или же надо сгладить какие-то помехи.

**Два основных типа:**

**Керамический (маленький, коричневый/жёлтый):**
```
    ──┤ ├──
```
- Полярности НЕТ
- Малая ёмкость (пикофарады, нанофарады)
- Используется в высокочастотных схемах

**Электролитический (цилиндр):**
```
        (+)
         │
       ─────
       ─────  ← Конденсатор
         │
        (-)
```
- **ЕСТЬ полярность!** Минус обычно помечен полосой
- Большая ёмкость (микрофарады)
- Взорвётся, если перепутать полярность!

Электролитический конденсатор на схемах всегда изображается со знаком плюс с той стороны где, соответственно, его надо втыкать плюсом.

**Что делает конденсатор:**
- **Заряжается:** Накапливает энергию при подключении питания
- **Разряжается:** Отдаёт энергию обратно в цепь
- **Сглаживает:** Выравнивает пульсации напряжения
- **Создаёт задержки:** В RC-цепях определяет время

**Постоянная времени RC:**

В схемах с конденсаторами часто фигурирует величина τ (тау), её значение это время за которое конденсатор зарядится/разрядится на ~63%. Обычно там где-то рядом в такой цепи резистор. Вот как считается τ:

```
τ = R × C

τ (тау) — время в секундах
R — сопротивление в омах
C — ёмкость в фарадах
```

**Пример:**
- R = 10kΩ = 10,000 Ω
- C = 100µF = 0.0001 F
- τ = 10,000 × 0.0001 = 1 секунда

### 4. Кнопка (тактовая кнопка)

Кнопка замыкает/размыкает цепь.

```
    Не нажата:       Нажата:

    ●─────────●      ●─────────●
                     │         │
    ●         ●      ●─────────●
```

**Четыре ножки:** Обычно противоположные пары уже соединены. Нажатие соединяет обе пары. _Обычно_ мы подключаем только две &md;sh; по диагонали.

**Дребезг контактов:**
При нажатии контакты "дребезжат" — замыкаются и размыкаются несколько раз очень быстро. Для точных схем нужно подавление дребезга (конденсатор параллельно кнопке). Просто знайте что такой эффект бывает, мы ещё поговорим о ней.

### 5. Транзистор (NPN)

> :warning: на самом деле чтобы начать собирать базовые схемы можно пока не читать про транзисторы. Если чувствуете что голова пухнет, лучше сходите проветритесь. Вернётесь к этому разделу когда будете готовы

Транзистор — это **управляемый выключатель** или **усилитель тока**. Деды это всё делали на вакуумных лампах, кстати, поэтому если вы хотите угорать по хардкору, можно легко получить плюсы к винтажности проекта, если заменить транзисторы на аналогичные _ламповые_ компоненты. Но придётся поднапрячь мозг, да.

Нас будет интересовать чёрный полубочонок-корпус [TO-92](https://en.wikipedia.org/wiki/TO-92), хотя если вы олдскул мазафака или ограбили дедушку на радиорынке, то вам может посчастливиться застать тразистор в красном трапецевидном корпусе [КТ-13](https://ru.wikipedia.org/wiki/%D0%9A%D0%A2315). Завидуем вам немножко в таком случае (но дедушку не обижайте).

**Распиновка 2N3904 / BC547:**
```
     (Вид снизу)

      ───┐
     │   │
     │ ●─┴─ Эмиттер (E)
     │ ●─── База (B)
     │ ●─── Коллектор (C)
      ───┘
```

**Как работает:**
```
         Коллектор (C)
              │
              ▼
        ────────────
       │            │
  База │  ────────  │
   ───→│            │
        ────────────
              │
              ▼
         Эмиттер (E)
```

Нарисовать как выглядит и работает транзистор тут в ASCII-схемы довольно проблемно, поэтому лучше загуглите как выглядит транзистор и полистайте ещё интернет хотя бы вот по двум ссылкам выше чтобы узнать как его обычно пишут на схемах. А мы сюда когда-нибудь картинку добавим.

**Принцип:**
- **Маленький ток** на базе (B, **B**ase) → **Большой ток** течёт через коллектор (C, **C**ollector) → эмиттер (E, **E**mitter).
- Коэффициент усиления (hFE): обычно 100-300
- Если ток базы = 0 → транзистор закрыт (не проводит)
- Если ток базы > 0 → транзистор открыт (проводит)

:warning: **Термины** изменчивы. В зависимости от того кого вы читаете, вы можете попасть вместо base/collector/emitter на затвор/сток/исток или gate/source/drain. Иногда это смешивается, типа могут ток с эмиттера обозначить как `I_d`. Короче, там нормально если будет ощущение что вы запутались, надо просто будет с ним пожить и пару раз перечитать.

**Три режима работы:**
1. **Ключ (выключатель):** Полностью открыт или закрыт — для управления светодиодами, моторами
2. **Усилитель:** Усиливает слабый сигнал — для аудио, датчиков
3. **Генератор:** В схемах автоколебаний — мультивибраторы, генераторы

**Пример:**
- Ток базы: 0.1 мА
- Коэффициент усиления: 100
- Ток коллектора: 0.1 мА × 100 = 10 мА ← достаточно для светодиода!

**Важно:**
- Эмиттер обычно подключается к минусу (GND)
- Резистор на базе ОБЯЗАТЕЛЕН (обычно 10kΩ) для ограничения тока
- Резистор в цепи коллектора нужен для нагрузки (светодиода и т.д.)

## Основные законы

### Закон Ома
```
V = I × R

Напряжение = Ток × Сопротивление
```

### Последовательное соединение
Компоненты друг за другом:
```
───[ R1 ]───[ R2 ]───[ R3 ]───

Общее сопротивление: R_total = R1 + R2 + R3
Ток и там и тут и сям одинаковый: I
Напряжение делится: V_total = V1 + V2 + V3
```

### Параллельное соединение
Компоненты рядом:
```
       ┌───[ R1 ]───┐
───────┤            ├───────
       │            │
       └───[ R2 ]───┘

Общее сопротивление: 1/R_total = 1/R1 + 1/R2
Напряжение и там и там одинаковое: V
Ток делится: I_total = I1 + I2
```

## Техника безопасности

### Что МОЖНО:
✓ Экспериментировать с 9V батарейкой
✓ Менять компоненты местами
✓ Пробовать разные номиналы
✓ Ошибаться и переделывать

### Что НЕЛЬЗЯ:
✗ Замыкать батарейку накоротко (+ напрямую на -)
✗ Включать светодиод без резистора
✗ Путать полярность электролитических конденсаторов
✗ Подавать на транзистор слишком большой ток на базу без резистора

### Признаки проблем:
- **Компонент сильно греется** → выключить питание, проверить схему
- **Дым, запах** → немедленно отключить!
- **Светодиод не горит** → проверить полярность, не сгорел ли
- **Ничего не работает** → проверить питание, контакты в макетке

## Как читать схемы в этой методичке

**Текстовые схемы:**
```
(+) → Резистор 220Ω → Светодиод → (-)
```
→ означает "соединить"

**ASCII-схемы:**
```
     (+9V)
       │
    [ 220Ω ]
       │
      ╱│╲  LED
       │
      (-)
```

**Обозначения компонентов:**
- Резистор: `[ 1kΩ ]` или `──┤  ├──`
- Светодиод: `LED` или `─▶├─`
- Конденсатор: `┤├` или `═══`
- Транзистор: `Q` или показано с выводами B, C, E
- Кнопка: `SW` или `○──○`

## Подход к обучению

### Философия этой программы:
1. **Делай сам** — лучший способ понять это собрать своими руками
2. **От простого к сложному** — каждое упражнение строится на предыдущем
3. **Видимый результат** — светится, пищит, реагирует
4. **Ошибки — это нормально** — не работает? Проверь полярность, контакты, попробуй ещё раз
5. **Что-то сгорело?** — ну, печально. Бывает. Замени компонент и попробуй снова. Первый сгоревший компонент можно торжественно сохранить для брелка например.

### Как работать с упражнениями:
1. Прочитай описание и схему
2. Подготовь компоненты
3. Собери схему на макетке
4. Подключи питание
5. Наблюдай результат
6. Экспериментируй (меняй номиналы, добавляй компоненты)
7. Сфотографируй/запиши работающую схему

В общем, не останавливайся на просто сделанном упражнении, запиши свои ощущения по результату.

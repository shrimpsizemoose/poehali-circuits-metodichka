# Упражнение 15: Сенсорная панель

**Категория:** Детекторы и сенсоры (бонус)  
**Время:** 40 минут  
**Сложность:** ⭐⭐⭐☆☆

## Цель
Создать чувствительную панель, которая реагирует на лёгкое прикосновение.

## Компоненты
- Транзисторы 2N3904 (1-2 шт)
- Фольга или металлическая пластина
- Резисторы 10MΩ, 220Ω
- Светодиод / пьезо

## Схема
```
Фольга → [10MΩ] → База Q1 → Усилитель → LED/Пьезо
```

## Применение
- Интерактивные арт-объекты
- Скрытые сенсоры в картинах
- Музыкальные установки

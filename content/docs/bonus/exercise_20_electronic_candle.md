# Упражнение 20: Электронная свеча

**Категория:** Комбинированные арт-схемы (бонус)<br>
**Время:** 60 минут<br>
**Сложность:** <span class="difficulty-stars"><span class="filled">★★★★</span><span class="empty">☆</span></span>

## Цель
Светодиод мерцает как настоящее пламя свечи — нерегулярно и естественно.

## Компоненты
- Транзисторы 2N3904 (2-3 шт)
- Светодиод жёлтый/оранжевый (яркий)
- Конденсаторы разных номиналов
- Резисторы

## Теория

### Как мерцает свеча?
Пламя свечи колеблется с **несколькими частотами**:
- Медленные колебания: 0.5-2 Гц (общее покачивание)
- Быстрые колебания: 5-10 Гц (мелкое дрожание)

### Решение
Два генератора с разными частотами влияют на один LED!

## Схема
```
Генератор 1 (медленный, ~1 Гц)  ┐
                                ├──→ LED
Генератор 2 (быстрый, ~8 Гц)    ┘

Оба влияют на яркость LED → эффект мерцания
```

## Реализация

### Вариант A: Два мультивибратора
Выходы обоих подаются на LED через резисторы

### Вариант B: Модуляция
Один мультивибратор управляет питанием второго

### Вариант C: RC-генератор + мультивибратор
Совместите разные схемы

## Настройка
Подбирайте конденсаторы, чтобы получить реалистичное мерцание:
- Слишком быстро → просто мигает
- Слишком медленно → не похоже на свечу
- **Правильно:** ~0.5-2 Гц медленно + ~5-10 Гц быстро

## Применение
- Декоративные "свечи" в арт-объектах
- Имитация огня в инсталляциях
- Романтическое освещение

## Эксперименты
1. **Разные цвета:** красный, оранжевый, жёлтый
2. **Несколько LED** для эффекта "костра"
3. **Добавить звук:** лёгкое потрескивание
4. **RGB-LED:** найдите многоцветный LED и сделайте мигание в нём сразу всех трёх компонент

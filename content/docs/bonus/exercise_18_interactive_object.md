# Упражнение 18: "Живой объект" (свет + звук + сенсор)

**Категория:** Комбинированные арт-схемы (бонус)  
**Время:** 90 минут  
**Сложность:** ⭐⭐⭐⭐☆

## Цель
Объединить несколько схем: объект реагирует на прикосновение светом И звуком одновременно!

## Компоненты
- Мультивибратор из упр. 10
- Сенсор касания из упр. 7/15
- Несколько LED
- Пьезоизлучатель

## Схема
```
Сенсор касания → Управляет мультивибратором
                      ↓
              LED мигают + Пьезо пищит
```

## Идея
1. В покое: всё выключено
2. При касании: мультивибратор запускается
3. LED мигают, пьезо издаёт ритмичные звуки
4. При отпускании: всё затихает

## Применение
Полноценный **интерактивный арт-объект**!

**Статус:** ✅ Объект живой!

# Упражнение 16: Детектор воды

**Категория:** Детекторы и сенсоры (бонус)<br>
**Время:** 30 минут<br>
**Сложность:** <span class="difficulty-stars"><span class="filled">★★</span><span class="empty">☆☆☆</span></span>

## Цель
Определять наличие воды между двумя контактами.

## Компоненты
- Транзистор 2N3904
- 2 гвоздя / скрепки (контакты)
- Резистор 100kΩ
- Светодиод / пьезо

## Теория
Вода проводит электричество (особенно с солью). Два контакта в воде замыкают цепь базы.

## Схема
```
Контакт 1 → (+)
Контакт 2 → [100k] → База Q1 → LED горит при наличии воды
```

## Эксперименты
- Чистая вода (слабо проводит)
- Подсоленная вода (отлично проводит)
- Мокрый палец

## Применение
- Датчик полива растений
- "Плачущая скульптура"
- Интерактивные инсталляции с водой

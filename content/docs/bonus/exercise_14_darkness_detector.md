## Теория

### Фоторезистор

**Фоторезистор** (LDR — Light Dependent Resistor) — резистор, сопротивление которого зависит от освещённости.

```
Яркий свет: R ≈ 100 Ω - 1 kΩ
Комнатное освещение: R ≈ 5-10 kΩ
Темнота: R ≈ 100 kΩ - 1 MΩ
```

### Делитель с фоторезистором

```
     (+9V)
       │
    ┌──┴──┐
  ФотоР   10kΩ
    └──┬──┘
       ├───→ V_out (к базе транзистора)
      GND

На свету: ФотоР ≈ 1kΩ
  V_out = 9V × (10k / 11k) ≈ 8.2V → транзистор открыт

В темноте: ФотоР ≈ 100kΩ
  V_out = 9V × (10k / 110k) ≈ 0.8V → транзистор едва открыт
```

**Обратная логика:** Поменяйте местами фоторезистор и резистор!

```
     (+9V)
       │
    ┌──┴──┐
   10kΩ  ФотоР
    └──┬──┘
       ├───→ V_out
      GND

На свету: V_out низкое → транзистор закрыт → LED не горит
В темноте: V_out высокое → транзистор открыт → LED горит!
```

### Два порога с двумя транзисторами

Q1 (чувствительный) → включает LED при сумерках
Q2 (менее чувствительный) → включает пищалку только в полной темноте

## Схема

### Вариант A: Простой (один транзистор)

```
        (+9V)
         │
    ┌────┼────┐
    │    │    │
  [10k] ФотоР [220Ω]
    │    │    │
    │    └────┼───→ База Q1
    │         │
    │        LED
    │         │
    │         C
    │   ┌─────┴─────┐
    │   │     Q1    │
    │   └─────┬─────┘
    │         E
    │         │
   GND       GND
```

### Вариант B: Два порога

```
        (+9V)
         │
    ┌────┼──────┼────┐
    │    │      │    │
  [10k] ФотоР [220Ω][1k]
    │    │      │    │
    │    └──┬───┼────┼──→ База Q1, Q2
    │       │  LED  PIEZO
    │      GND  │    │
    │           C1   C2
    │     ┌─────┴─┬──┴─┐
    │     │  Q1   │ Q2 │
    │     └───┬───┴──┬─┘
    │         E1    E2
   GND       └──┬───┘
                │
               GND
```

Подберите разные резисторы для Q1 и Q2, чтобы они срабатывали при разной освещённости.

## Пошаговая инструкция (Вариант A)

### Шаг 1: Делитель напряжения
1. Резистор 10kΩ: (+) → ряд 5
2. Фоторезистор: ряд 5 → GND
3. Точка соединения (ряд 5) — выход делителя

### Шаг 2: Транзистор
1. Q1: E → GND, B ← ряд 5, C → LED

### Шаг 3: Светодиод
1. (+) → резистор 220Ω → LED → коллектор Q1

### Шаг 4: Тестирование
- Посветите фонариком на фоторезистор → LED гаснет
- Накройте фоторезистор рукой → LED загорается!

## Эксперименты

1. **Обратная логика:** Поменяйте местами резистор и фоторезистор
2. **Настройка чувствительности:** Меняйте резистор 10kΩ на 1kΩ или 100kΩ
3. **LED-фотодиод:** Вместо фоторезистора используйте второй LED наоборот (анод к GND, катод к делителю) — работает!

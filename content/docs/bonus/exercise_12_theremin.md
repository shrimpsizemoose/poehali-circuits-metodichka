## Теория

### Что такое терменвокс?

**Терменвокс** (Theremin) — первый электронный музыкальный инструмент (1920 год, Лев Термен).

**Принцип:** Две антенны детектируют положение рук музыканта:
- **Вертикальная антенна:** Расстояние → высота звука
- **Горизонтальная антенна:** Расстояние → громкость

### Тело как конденсатор

Ваше тело имеет **ёмкость** относительно земли: ~100-200 пФ.

```
     Рука
      ║
      ║  Воздух = диэлектрик
      ║
   Антенна ──→ к схеме

Ёмкость между рукой и антенной: ~1-50 пФ (зависит от расстояния)
```

**Ближе рука → больше ёмкость**

### Как это меняет частоту?

В RC-генераторе:
```
f = 1 / (RC)

C_total = C_конденсатор + C_антенна + C_рука

Рука близко → C_total больше → f ниже → звук ниже
Рука далеко → C_total меньше → f выше → звук выше
```

## Пошаговая инструкция

### Шаг 1: Базовый генератор
Соберите генератор как в упр. 9, но с изменениями:
- Резистор коллектора: 1kΩ
- **Вместо LED → пьезоизлучатель**
- Резистор базы: **1MΩ или 10MΩ** (коричневый-чёрный-синий или коричневый-чёрный-фиолетовый)
- Конденсатор: 0.01-0.1µF (керамический)

### Шаг 2: Антенна
1. Возьмите провод длиной 10-15 см
2. Очистите один конец
3. Подключите к **базе транзистора** (или к точке между резистором базы и базой)
4. Второй конец оставьте **в воздухе** (не подключён!)

### Шаг 3: Тестирование
1. Подключите батарейку
2. Пьезо должен **пищать**
3. **Приближайте/отдаляйте руку к антенне (5-15 см)**
4. **Звук должен меняться!** 🎵

## Эксперименты

### Эксперимент 1: Разные антенны

| Антенна | Чувствительность |
|---------|------------------|
| Короткий провод (5 см) | Низкая (нужно касаться) |
| Средний провод (15 см) | Хорошая |
| Длинный провод (30+ см) | Очень чувствительная |
| Фольга (площадь 10×10 см) | Максимальная |

### Эксперимент 2: Разные резисторы

| R_базы | Эффект |
|--------|--------|
| 100kΩ | Низкая чувствительность |
| 1MΩ | Хорошо |
| 10MΩ | Очень чувствительно |

### Эксперимент 3: Диапазон частот
Меняйте конденсатор для разных диапазонов:
- 0.001µF → очень высокий писк
- 0.01µF → средний
- 0.1µF → низкий бубнящий звук

### Эксперимент 4: "Игра" на терменвоксе
Попробуйте сыграть простую мелодию, меняя расстояние до антенны!

## Возможные проблемы

### Звук не меняется

**Причина 1: Резистор базы слишком маленький**
- **Решение:** Используйте 1MΩ или больше

**Причина 2: Антенна слишком короткая**
- **Решение:** Используйте провод 15-20 см

**Причина 3: Конденсатор слишком большой**
- **Решение:** Используйте 0.01-0.1µF

### Очень нестабильный звук

**Причина:** Слишком чувствительная схема
- **Решение:** Уменьшите резистор базы до 100kΩ - 1MΩ
- Или добавьте небольшой конденсатор параллельно антенне (10-100 пФ)

### Не пищит вообще

**Причина:** Генератор не работает
- **Решение:** Сначала проверьте без антенны (должен пищать стабильно)

## Настоящий терменвокс

В настоящем терменвоксе используются **два генератора**:
1. Опорный генератор (фиксированная частота)
2. Управляемый генератор (частота зависит от руки)

Их частоты **смешиваются**, и мы слышим **разностную частоту**.

Наша схема — упрощённая версия с одним генератором.

## Теория

### Что такое звук?

**Звук** — это волны сжатия и разрежения воздуха.

**Частота звука:**
- 20 Гц - 20,000 Гц → слышимый диапазон человека
- < 20 Гц → инфразвук (не слышим)
- > 20,000 Гц → ультразвук (не слышим)

**Высота тона:**
- Низкие частоты (100-200 Гц) → бубнение, бас
- Средние (400-1000 Гц) → речь
- Высокие (2000-8000 Гц) → писк, свист

### Пьезоизлучатель

**Пьезоэффект:** Некоторые материалы при деформации создают напряжение (и наоборот).

```
Электрический сигнал → Пьезокристалл вибрирует → Звук
```

**Преимущества:**
- Дешёвый (30-50₽)
- Громкий
- Не нужен усилитель

**Недостатки:**
- Противный писклявый звук
- Узкий частотный диапазон

### Динамик

**Принцип:** Электромагнит двигает мембрану.

```
Ток → Электромагнит → Мембрана вибрирует → Звук
```

**Для подключения динамика:** Обязательно через резистор ~220Ω, иначе сгорит транзистор (слишком большой ток).

### Частота звука из RC

```
f = 1 / (1.4 × R × C)

Для слышимого звука нужно f = 200-8000 Гц
```

**Примеры:**
- R=10kΩ, C=10µF → f ≈ 7 Гц (НЕ слышно, мигает)
- R=10kΩ, C=0.01µF → f ≈ 7 кГц (высокий писк)
- R=1kΩ, C=0.1µF → f ≈ 7 кГц (высокий писк)

## Схема

### Модификация мультивибратора

**Было:**
```
Коллектор Q1 → LED1 → (+)
Коллектор Q2 → LED2 → (+)
```

**Стало:**
```
Коллектор Q1 → LED1 → (+)
Коллектор Q2 → Пьезо/динамик → (+)
```

### ASCII-схема
```
        (+9V)
         │
    ┌────┼────┐
    │    │    │
  [1k] [10k] [220Ω]
    │    │     │
   LED   │   PIEZO/
    │    │   Speaker
    C1───┼────C2
    │    │    │
    B1  Q1   B2  Q2
    └─┬──┘   └─┬──┘
      E1───────E2
            │
           (-)

Перекрёстные связи:
C1 ──┤├ 10µF ──→ B2
C2 ──┤├ 0.01µF ──→ B1  ← Меньший конденсатор для звука!
```

## Пошаговая инструкция

### Начальное состояние
У вас должен быть собран мультивибратор из упр. 10.

### Шаг 1: Изменение частоты
1. Замените один из конденсаторов (C1 или C2) на **маленький**:
   - C1 = 10µF (оставляем для мигания LED)
   - C2 = 0.01µF = 10nF = 10,000pF (керамический!)

> Керамические конденсаторы обычно маркированы цифрами: "103" = 10,000pF = 0.01µF

### Шаг 2: Подключение пьезоизлучателя
1. **Отключите батарейку**
2. Вместо LED2 вставьте **пьезоизлучатель**:
   - Один вывод → коллектор Q2
   - Второй вывод → (+)

> **Полярность пьезо:** Обычно не важна, но на некоторых есть маркировка (+/-). Если тихо звучит — попробуйте перевернуть.

**Если используете динамик:**
1. Подключите через резистор 220Ω:
   - Коллектор Q2 → резистор 220Ω → динамик → (+)

### Шаг 3: Тестирование
1. Подключите батарейку
2. **Должны наблюдать:**
   - LED1 медленно мигает (~1 Гц)
   - Пьезо ПИЩИТ (~700 Гц - 7 кГц, зависит от точного номинала)

## Что наблюдать

✓ **Светодиод мигает** (медленная частота от большого C1)
✓ **Пьезо пищит** (быстрая частота от маленького C2)
✓ **Противный высокий звук** 🔊

## Эксперименты

### Эксперимент 1: Разная высота звука

Меняйте конденсатор C2:

| C2 | Частота | Звук |
|----|---------|------|
| 0.001µF (1nF) | ~70 кГц | Не слышно (ультразвук) |
| 0.01µF (10nF) | ~7 кГц | Высокий писк |
| 0.1µF (100nF) | ~700 Гц | Средний тон |
| 1µF | ~70 Гц | Низкое бубнение |
| 10µF | ~7 Гц | Не слышно (мигает) |

### Эксперимент 2: Музыкальные ноты

Подберите RC для конкретных нот:

| Нота | Частота | Примерное RC (R=10kΩ) |
|------|---------|-----|
| До (C4) | 262 Гц | C ≈ 0.27µF |
| Ми (E4) | 330 Гц | C ≈ 0.22µF |
| Соль (G4) | 392 Гц | C ≈ 0.18µF |
| До (C5) | 523 Гц | C ≈ 0.14µF |

### Эксперимент 3: Два пьезо
Подключите пьезо к **обоим** коллекторам:
- Результат: Два разных тона по очереди (если C1 ≠ C2)

### Эксперимент 4: Сирена
Сделайте **асимметричную** схему:
- C1 = 0.01µF → высокий тон
- C2 = 0.1µF → низкий тон
- Результат: "Би-бо, би-бо" как сирена! 🚨

## Возможные проблемы

### Не слышно звука

**Причина 1: Частота слишком высокая или низкая**
- **Решение:** Используйте C = 0.01-0.1µF

**Причина 2: Пьезо не подключён**
- **Решение:** Проверьте контакты

**Причина 3: Схема не работает**
- **Решение:** Сначала проверьте с LED (должен мигать)

### Очень тихий звук

**Причина 1: Пьезо включён наоборот**
- **Решение:** Переверните выводы

**Причина 2: Динамик без усилителя**
- Динамик 8Ω требует больше тока
- **Решение:** Используйте пьезо или добавьте усилительный каскад

### Транзистор греется (с динамиком)

**Причина:** Слишком большой ток
- **Решение:** Добавьте резистор 220Ω последовательно с динамиком

# Упражнение 13: "Орган" на кнопках

**Категория:** Звуковые упражнения (бонус)
**Время:** 60 минут
**Сложность:** ⭐⭐⭐⭐☆

---

## Цель

Создать примитивный музыкальный инструмент: разные кнопки издают разные ноты!

---

## Что учим

- **Параллельное переключение конденсаторов**
- **Музыкальные частоты**
- **Многокнопочное управление**

---

## Необходимые компоненты

| Компонент | Количество | Примечание |
|-----------|------------|------------|
| Генератор из упр. 9/11 | 1 | С пьезо |
| Кнопки тактовые | 3-5 | |
| Конденсаторы разных номиналов | 3-5 | 1µF, 2.2µF, 4.7µF, 10µF, 22µF |

---

## Теория

### Музыкальные ноты и частоты

| Нота | Частота | Примерный C (при R=10kΩ) |
|------|---------|--------------------------|
| До (C4) | 262 Гц | 0.27 µF |
| Ре (D4) | 294 Гц | 0.24 µF |
| Ми (E4) | 330 Гц | 0.22 µF |
| Фа (F4) | 349 Гц | 0.20 µF |
| Соль (G4) | 392 Гц | 0.18 µF |
| Ля (A4) | 440 Гц | 0.16 µF |
| Си (B4) | 494 Гц | 0.14 µF |

### Принцип работы

Каждая кнопка подключает **свой конденсатор параллельно** основному:

```
Базовый генератор с C_base

Кнопка 1 нажата → C_total = C_base + C1 → частота f1
Кнопка 2 нажата → C_total = C_base + C2 → частота f2
...
```

---

## Схема

```
     Генератор
     (упр. 9)
         │
         B (база)
         │
         ├──── C_base (постоянный)
         │
         ├──┤○├─┤├ C1 ──→ GND  (кнопка 1)
         │
         ├──┤○├─┤├ C2 ──→ GND  (кнопка 2)
         │
         ├──┤○├─┤├ C3 ──→ GND  (кнопка 3)
         │
        ...
```

**Каждая кнопка:** база → кнопка → конденсатор → GND

---

## Пошаговая инструкция

### Шаг 1: Базовый генератор
Соберите генератор с пьезо (упр. 11)

### Шаг 2: Первая кнопка
1. Кнопка 1: одна ножка к **базе транзистора**, вторая к конденсатору C1
2. Конденсатор C1 (например, 1µF): одна ножка к кнопке, вторая к **GND**

### Шаг 3: Дополнительные кнопки
Повторите для кнопок 2, 3, 4, 5 с разными конденсаторами

### Шаг 4: Игра!
Нажимайте кнопки — каждая издаёт свою ноту!

---

## Возможные проблемы

### Все кнопки звучат одинаково

**Причина:** Конденсаторы слишком близких номиналов
- **Решение:** Используйте сильно различающиеся: 1µF, 2.2µF, 4.7µF, 10µF, 22µF

### Звук очень нестабильный

**Причина:** Дребезг кнопок
- **Решение:** Добавьте маленький конденсатор (100pF) параллельно каждой кнопке

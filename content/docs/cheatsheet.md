# Шпаргалка по схемотехнике

## ⚡ Основные формулы

### Закон Ома
```
V = I × R
I = V / R
R = V / I

V — напряжение (Вольты)
I — ток (Амперы)
R — сопротивление (Омы)
```

### Мощность
```
P = V × I = I² × R = V² / R

P — мощность (Ватты)
```

### RC-цепь (постоянная времени)
```
τ = R × C

τ — время (секунды)
R — сопротивление (Омы)
C — ёмкость (Фарады)

Полный заряд/разряд: t = 5τ
```

### Частота RC-генератора
```
f ≈ 1 / (1.4 × R × C)

f — частота (Герцы)
```

### Делитель напряжения
```
V_out = V_in × (R2 / (R1 + R2))
```

## 🔌 Полярность компонентов

### Светодиод
```
Длинная ножка = Анод (+)
Короткая ножка = Катод (-)
Большой кристалл внутри = Катод (-)
```

### Электролитический конденсатор
```
Длинная ножка = Плюс (+)
Короткая ножка = Минус (-)
Полоса на корпусе = Минус (-)
```

### Транзистор NPN (2N3904)
```
Вид снизу, плоская сторона вверх:
E — B — C (слева направо)

E = Эмиттер (обычно к GND)
B = База (управление)
C = Коллектор (к нагрузке)
```

### Транзистор NPN (BC547)
```
Вид снизу, плоская сторона вверх:
C — B — E (слева направо)
```

## 🔋 Батарейка 9V (Крона)

```
Напряжение: 9V (свежая), 7-8V (разряженная)
Ёмкость: ~500 мАч
Ток: до 500 мА кратковременно

Один LED потребляет: ~15-20 мА
Пять LED: ~75-100 мА
Время работы: 500 мАч / 100 мА = 5 часов
```

## 💡 Светодиоды

| Цвет | Прямое напряжение | Ток |
|------|-------------------|-----|
| Красный | ~2V | 10-20 мА |
| Жёлтый/Зелёный | ~2.2V | 10-20 мА |
| Синий/Белый | ~3-3.5V | 10-20 мА |

### Расчёт резистора для LED
```
R = (V_батареи - V_LED) / I_LED

Пример (красный LED, 9V):
R = (9V - 2V) / 0.015A = 467Ω → берём 220Ω или 470Ω
```

## 🔧 Транзистор NPN

### Режимы работы
```
Закрыт: V_базы < 0.6V → I_коллектора ≈ 0
Открыт: V_базы > 0.7V → I_коллектора = большой
```

### Коэффициент усиления
```
I_коллектора = hFE × I_базы

hFE (2N3904/BC547) ≈ 100-300

Пример:
I_базы = 0.1 мА
hFE = 100
I_коллектора = 10 мА
```

### Типовая схема (ключ)
```
     (+)
      │
    [R_нагрузки] (220Ω - 1kΩ)
      │
    Нагрузка (LED)
      │
      C ──┐
          │ Транзистор
      B ──┤
          │
      E ──┘
      │
     GND

Управление:
(+) → [R_базы] (10kΩ) → Кнопка → База
```

## 🔌 Макетная плата (breadboard)

### Соединения
```
Горизонтальные ряды (1, 2, 3...):
  Отверстия в одном ряду соединены
  (только до центральной канавки)

Вертикальные шины (по краям):
  + и - шины для питания
  Все отверстия в шине соединены

Центральная канавка:
  Разделяет левую и правую стороны
```

## 📐 Последовательное и параллельное соединение

### Последовательное
```
──[ R1 ]──[ R2 ]──[ R3 ]──

Сопротивление: R_total = R1 + R2 + R3
Ток: I везде одинаковый
Напряжение: V_total = V1 + V2 + V3
```

### Параллельное
```
    ┌──[ R1 ]──┐
────┤          ├────
    └──[ R2 ]──┘

Сопротивление: 1/R_total = 1/R1 + 1/R2
Ток: I_total = I1 + I2
Напряжение: V везде одинаковое
```

## 🎛️ Мультивибратор

### Частота мигания (один полуцикл)
```
T = 0.7 × R_базы × C

Пример (симметричный):
R = 10kΩ, C = 10µF
T = 0.7 × 10,000 × 0.00001 = 0.07 сек

Частота = 1/T = 14 Гц (каждый LED)
```

### Типовые номиналы
```
R_коллектора = 1kΩ (для LED)
R_базы = 10kΩ - 100kΩ
C = 10µF - 100µF

Быстрое мигание: C = 1-10µF
Медленное: C = 100-1000µF
```

## 🔍 Отладка схем

### Светодиод не горит
1. ☐ Проверьте полярность LED
2. ☐ Проверьте наличие резистора
3. ☐ Проверьте батарейку (мультиметр)
4. ☐ Проверьте контакты в макетке
5. ☐ Попробуйте другой LED (может сгорел)

### Транзистор не переключает
1. ☐ Проверьте распиновку (E-B-C)
2. ☐ Проверьте резистор базы (10kΩ)
3. ☐ Проверьте эмиттер → GND
4. ☐ Попробуйте другой транзистор

### Мультивибратор не мигает
1. ☐ Проверьте полярность конденсаторов
2. ☐ Проверьте перекрёстные связи
3. ☐ Проверьте эмиттеры соединены
4. ☐ Попробуйте другие конденсаторы

## 🛡️ Техника безопасности

### ✅ МОЖНО
- Эксперименты с 9V батарейкой
- Менять компоненты местами
- Пробовать разные номиналы
- Ошибаться!

### ❌ НЕЛЬЗЯ
- Замыкать батарейку (+) напрямую на (-)
- LED без резистора
- Путать полярность электролитических конденсаторов
- Подавать ток на базу транзистора без резистора

### 🔥 Признаки проблем
```
Компонент греется → ВЫКЛЮЧИТЬ!
Дым, запах → ВЫКЛЮЧИТЬ НЕМЕДЛЕННО!
LED не горит → проверить полярность
```

## 🎓 Основные понятия

**Напряжение (V)** — "давление" электричества, Вольты
**Ток (I)** — "поток" электричества, Амперы
**Сопротивление (R)** — "сопротивление потоку", Омы
**Мощность (P)** — "расход энергии", Ватты

**Полярность** — направление (+) и (-)
**Земля (GND)** — общий минус, точка отсчёта 0V

**Анод** — положительный вывод
**Катод** — отрицательный вывод

**Делитель напряжения** — два резистора дают часть напряжения
**RC-цепь** — резистор + конденсатор = задержка
**Обратная связь** — выход влияет на вход

## 📖 Как пользоваться методичкой

### Порядок работы

1. **Прочитайте [Введение](./intro)** — там основы и теория
2. **Вечер 1:** Упражнения 1-5 подряд
3. **Вечер 2:** Упражнения 6-8 подряд
4. **Вечер 3:** Упражнения 9-10 (финал!)
5. **Бонус:** Упражнения 11-20 по желанию

### Структура каждого упражнения

- **Цель** — что будем делать
- **Теория** — как это работает
- **Схема** — что куда подключать
- **Пошаговая инструкция** — детальные шаги
- **Эксперименты** — что попробовать дополнительно
- **Возможные проблемы** — как починить
- **Применение** — где используется в реальной жизни

### Советы

✅ **Делайте:**
- Фотографируйте работающие схемы
- Записывайте наблюдения
- Экспериментируйте с номиналами
- Не бойтесь ошибок!

❌ **Не делайте:**
- Не пропускайте теорию
- Не торопитесь
- Не замыкайте батарейку накоротко
- Не подключайте светодиоды без резисторов

## 🎨 Философия программы

### Для художников, не инженеров

Эта методичка создана специально для **творческих людей**, которые хотят использовать электронику в своих арт-проектах.

**Мы НЕ учим:**
- Сложной математике
- Профессиональной схемотехнике
- Программированию (пока)

**Мы учим:**
- **Понимать** как работают компоненты
- **Чувствовать** электрические цепи
- **Экспериментировать** и создавать
- **Воплощать** творческие идеи в электронике

### От простого к сложному

Каждое упражнение строится на предыдущем:
```
LED → Кнопка → Несколько LED → RC-цепь →
  → Транзистор → Датчики → Генератор → МУЛЬТИВИБРАТОР!
```

### Видимый результат

Все схемы **светятся**, **пищат**, **реагируют**. Никаких абстрактных теорий — только практика!

## 🚀 Что дальше?

### На экспедиции

После этой подготовки вы будете работать с **ATtiny85** — крошечным программируемым микроконтроллером.

**Возможности ATtiny85:**
- Программируемая логика
- Управление множеством LED
- Чтение датчиков
- ШИМ (плавная яркость)
- Генерация сложных звуков
- Энергонезависимая память

**Комбинация навыков:**
Аналоговые схемы (эта методичка) + Программирование (ATtiny85) = **Мощные интерактивные объекты!**

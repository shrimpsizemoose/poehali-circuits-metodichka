# Упражнение 04: Два светодиода последовательно

**Вечер:** 1 (Основы)<br>
**Время:** 15 минут<br>

## Цель

Два светодиода соединены в цепочку (один за другим). Учимся последовательному соединению и понимаем, почему они горят тусклее.

---

## Что учим

- **Последовательное соединение:** компоненты друг за другом
- **Напряжение делится** между компонентами
- **Ток одинаковый** во всей цепи
- **Почему светодиоды горят тусклее**

---

## Необходимые компоненты

| Компонент | Количество | Примечание |
|-----------|------------|------------|
| Макетная плата с питанием | 1 | |
| Светодиоды (лучше одного цвета) | 2 | |
| Резистор 220Ω | 1 | Только один! |
| Провода для макетки | 2-4 | |

---

## Теория

### Что такое последовательное соединение?

При последовательном соединении компоненты включены **друг за другом**, как вагоны поезда.

```
(+) ──[ Комп.1 ]──[ Комп.2 ]──[ Комп.3 ]── (-)
```

Ток течёт через все компоненты **по очереди**.

**Ключевые свойства:**
- **Ток** через все компоненты **одинаковый**
- **Напряжение делится** между компонентами
- Если один компонент выйдет из строя, **вся цепь перестанет работать**

### Законы последовательного соединения

**Ток:**
```
I_total = I1 = I2 = I3 = ...
```
Ток везде одинаковый (закон сохранения заряда).

**Напряжение:**
```
V_total = V1 + V2 + V3 + ...
```
Общее напряжение = сумма напряжений на каждом компоненте.

**Сопротивление (для резисторов):**
```
R_total = R1 + R2 + R3 + ...
```

### Деление напряжения

Напряжение источника (9V) делится между всеми компонентами в цепи.

**Пример с двумя светодиодами:**
```
V_батареи = 9V

V = V_резистора + V_LED1 + V_LED2

Если каждый LED "забирает" ~2V:
9V = V_резистора + 2V + 2V
V_резистора = 9V - 4V = 5V
```

**Почему светодиоды горят тусклее?**

При параллельном соединении (упр. 3):
- Каждый светодиод получает полное напряжение (9V минус падение на резисторе)
- Ток через каждый: ~15-20 мА

При последовательном соединении:
- Напряжение делится на два (каждый LED получает меньше)
- Ток меньше (общее сопротивление цепи выше)
- Результат: **светодиоды горят тусклее**

### Расчёт тока

Приблизительно:
```
V_источника = 9V
V_LED1 = 2V
V_LED2 = 2V
V_резистора = 9 - 2 - 2 = 5V

I = V_резистора / R = 5V / 220Ω ≈ 23 мА
```

Этого достаточно для свечения, но яркость будет ниже, чем при параллельном соединении.

## Схема

### Текстовое описание
```
Батарея (+) → Резистор 220Ω → Светодиод1 → Светодиод2 → Батарея (-)
```

### ASCII-схема
```
    (+9V)
      │
    [220Ω]
      │
     ╱│╲
    ╱ │ ╱  LED1 (анод вверх)
   ────────
      │
     ╱│╲
    ╱ │ ╱  LED2 (анод вверх)
   ────────
      │
     (-)
```

### Схема на макетке
```
Шина (+) ═══════════════════════════
              │
            [220Ω]
              │
        Ряд 5: ●─LED1─● (анод)
        Ряд 6: ●─LED1─● (катод)
              │
        Ряд 7: ●─LED2─● (анод)
        Ряд 8: ●─LED2─● (катод)
              │
Шина (-) ═══════════════════════════
```

**Важно:** Катод первого светодиода соединён с анодом второго!

## Пошаговая инструкция

### Шаг 1: Подготовка
1. **Отключите батарейку**
2. Очистите макетку

### Шаг 2: Резистор
1. Вставьте резистор 220Ω:
   - Одна ножка в **шину (+)**
   - Вторая в **ряд 5**

### Шаг 3: Первый светодиод (LED1)
1. Вставьте светодиод 1:
   - **Анод** (длинная ножка) в **ряд 5** (с резистором)
   - **Катод** (короткая ножка) в **ряд 6**

### Шаг 4: Второй светодиод (LED2)
1. Вставьте светодиод 2:
   - **Анод** (длинная ножка) в **ряд 6** (к катоду LED1!)
   - **Катод** (короткая ножка) в **ряд 7**

> **Важно:** Анод LED2 соединяется с катодом LED1 — светодиоды в цепочке!

### Шаг 5: Замыкание на землю
1. Провод от **ряда 7** (катод LED2) к **шине (-)**

### Шаг 6: Проверка
1. Подключите батарейку
2. **Оба светодиода должны загореться, но тусклее, чем по отдельности** 💡💡

✓ **Яркость обоих светодиодов одинаковая** (через них течёт один ток)

## Эксперименты

### Эксперимент 1: Выключение одного светодиода
1. Выньте **один любой светодиод** из макетки
2. **Результат:** Второй светодиод **тоже гаснет**!

**Вывод:** При последовательном соединении **разрыв цепи в любом месте** останавливает весь ток. Все компоненты зависимы.

### Эксперимент 2: Три-четыре светодиода
Добавьте ещё 1-2 светодиода в цепочку:
```
(+) → Резистор → LED1 → LED2 → LED3 → LED4 → (-)
```

**Результат:**
- С **двумя светодиодами:** горят тускло
- С **тремя:** ещё тусклее
- С **четырьмя:** еле светятся
- С **пятью:** могут вообще не загореться (не хватает напряжения)

**Почему:**
Каждый светодиод "забирает" ~2V. При 9V можно последовательно включить максимум 3-4 красных светодиода.

### Эксперимент 3: Разные цвета
Попробуйте соединить последовательно светодиоды разных цветов:
- Красный (2V) + Синий (3V) = 5V → горят нормально
- Два синих (3V + 3V) = 6V → горят тускло

**Вывод:** Разные светодиоды имеют разное падение напряжения.

### Эксперимент 4: Сравнение с параллельным соединением

Соберите рядом:
- **Слева:** два светодиода параллельно (как в упр. 3)
- **Справа:** два светодиода последовательно (текущая схема)

**Результат:**
- Параллельные — **яркие**
- Последовательные — **тусклые**

**Вывод:** Для максимальной яркости используйте параллельное соединение.

## Возможные проблемы

### Светодиоды не горят вообще

**Причина 1: Неправильная полярность**
- Проверьте, что анод LED2 соединён с катодом LED1
- **Решение:** Переверните светодиоды

**Причина 2: Слишком много светодиодов**
- 5+ светодиодов последовательно не загорятся от 9V
- **Решение:** Уберите лишние

**Причина 3: Разряженная батарейка**
- **Решение:** Замените батарейку

### Один светодиод горит ярко, второй еле светится

**Причина:** Светодиоды разных типов (разное падение напряжения)
- **Решение:** Используйте светодиоды одного типа

### Светодиоды горят, но очень тускло

**Причина:** Резистор слишком большой
- **Решение:** Попробуйте резистор меньшего номинала (100Ω или 47Ω)

> **Внимание:** С маленьким резистором ток может быть слишком большим для светодиодов при последовательном соединении. Будьте аккуратны!

---

## Сравнение: Параллельное vs Последовательное

| Параметр | Параллельное | Последовательное |
|----------|--------------|------------------|
| **Напряжение** | Одинаковое на всех | Делится между всеми |
| **Ток** | Делится между ветками | Одинаковый везде |
| **Яркость LED** | Высокая | Ниже |
| **Независимость** | Да (один сгорел — другие работают) | Нет (один сгорел — все гаснут) |
| **Количество LED** | Ограничено током батареи | Ограничено напряжением |
| **Резисторы** | Каждому LED свой | Один на всю цепь |

---

## Применение

Когда используется последовательное соединение:
- 🎄 **Старые гирлянды** (если одна лампочка перегорала, гирлянда не работала)
- 🔋 **Батарейки в фонарике** (несколько батареек последовательно для большего напряжения)
- 📱 **Делители напряжения** (для получения разных напряжений из одного источника)

**Современные гирлянды** используют параллельное соединение! Ну, должны.

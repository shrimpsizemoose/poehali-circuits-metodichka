## Теория

### Что такое кнопка (тактовая кнопка)?

Тактовая кнопка — это механический выключатель. При нажатии она замыкает контакты, при отпускании — размыкает.

**Конструкция:**
```
     Вид сверху:        Вид сбоку:

    ┌───────────┐     ┌───────────┐
    │  ●    ●   │     │     ○     │ ← Кнопка
    │           │     │  ───┴───  │
    │     ○     │     │  │     │  │
    │           │     │  ●     ●  │
    │  ●    ●   │     └───────────┘
    └───────────┘

    ● — ножки
    ○ — кнопка для нажатия
```

**Как работает:**
```
    НЕ НАЖАТА:          НАЖАТА:

  A ●─────────● Y     A ●─────────● Y
                        │         │
  X ●         ● D     X ●─────────● D

    Цепь разомкнута     Цепь замкнута
    Ток НЕ течёт        Ток течёт
    между B и C         между X и Y
    Ток НЕ течёт        Ток течёт
    между A и D         между A и D
```

### Распиновка тактовой кнопки

У кнопки **4 ножки**, но обычно они соединены попарно:
- **Верхние две** уже соединены между собой
- **Нижние две** уже соединены между собой
- При нажатии **верхние соединяются с нижними**

```
      1 ●───────● 2
        │       │
        │   ○   │  ← Кнопка
        │       │
      3 ●───────● 4

До нажатия: 1-2 соединены, 3-4 соединены
При нажатии: все 1-2-3-4 соединены
```

**Как правильно установить:**
Кнопка часто имеет прямоугольную форму. Устанавливайте её **поперёк центральной канавки макетки**, чтобы ножки попали в разные ряды. Это должно быть немного с усилием, но с небольшим. Если усилие большое, вы скорее всего что-то делаете не так.

### Дребезг контактов

При нажатии на механическую кнопку контакты не замыкаются мгновенно — они "дребезжат", это прям механический процесс дрыг-дрыг:

```
  Нажали
    ↓
    ┌─┐┌─┐┌──────────
────┘ └┘ └┘          ← Сигнал "прыгает"

    ~5-50 мс дребезга
```

Для этого упражнения дребезг **не важен** (светодиод мигнёт так быстро, что мы не заметим). Для цифровых схем дребезг нужно подавлять конденсатором или программно. Просто знайте что такое явление есть и оно может объяснять почему что-то не работает так как вы хотите.

## Схема

### Текстовое описание
```
Батарея (+) → Кнопка → Резистор 220Ω → Светодиод → Батарея (-)
```

### ASCII-схема
```
    +9V
     │
     │
   ┌─┴─┐
   │ ○ │ Кнопка
   └─┬─┘
     │
    ┌┴┐
    │R│ Резистор 220Ω
    └┬┘
     │
    ╱│╲
   ╱ │ ╲ Светодиод
  ────────
     │
     │
    GND
```

### Схема на макетке
```
Шина (+) ═══════════════════════════
           │
   Ряд 8:  ●─────●  ← Верхние ножки кнопки
           │  ○  │
   Ряд 10: ●─────●  ← Нижние ножки кнопки
                 │
              [220Ω]
                 │
   Ряд 12: ●──LE───● (анод)
   Ряд 13: ●───ED──● (катод)
           │
Шина (-) ═══════════════════════════
```

Короче, задача простроить "цепь" от плюса к минусу, каждое "звено" это или провод или компонент и мы ищем "путь" от плюса к минусу.

## Пошаговая инструкция

### Начальное состояние
У вас должна уже есть схема из [Упражнения 01](../exercise_01_first_led). Ведь есть же, да?
```
(+) → Резистор → Светодиод → (-)
```
Светодиод горит постоянно. _Эта светомузыка будет вечной, если я заменю батарейки_

### Шаг 1: Отключение питания
1. **Отключите батарейку** от макетки (для безопасности)

### Шаг 2: Разрыв цепи
1. Найдите провод, который идёт от **шины (+)** к резистору
2. **Выньте этот провод** из шины (+)

Теперь цепь разомкнута.

### Шаг 3: Установка кнопки
1. Возьмите тактовую кнопку
2. Установите её **поперёк центральной канавки** макетки
3. Две ножки должны быть в одной половине, две — в другой
4. Например: верхние ножки в ряд 8, нижние — в ряд 10

### Шаг 4: Подключение кнопки
1. Провод от **шины (+)** вставьте в ряд с **верхней ножкой кнопки** (ряд 8)
2. Провод от ряда с **нижней ножкой кнопки** (ряд 10) вставьте к резистору

Схема теперь:
```
(+) → Кнопка → Резистор → Светодиод → (-)
```

### Шаг 5: Проверка
1. Подключите батарейку
2. **Не нажимая кнопку:** светодиод НЕ горит
3. **Нажмите кнопку:** светодиод загорается! 💡
4. **Отпустите кнопку:** светодиод гаснет
5. Скажите громко вслух "ОХ НИХУЯ СЕБЕ ВОТ ЭТО ПРИКОЛ!". Так ваши соседи поймут что вы сделали что-то интересное. Ладно, можно что-то аналогичное без мата если вы прям ханжа.

## Эксперименты

### Эксперимент 1: Местоположение кнопки
Попробуйте переместить кнопку в другую часть цепи:

**Вариант A:** Кнопка после светодиода
```
(+) → Резистор → Светодиод → Кнопка → (-)
```
**Результат:** Работает точно так же! Кнопка разрывает цепь, неважно где.

**Вариант Б:** Кнопка между резистором и светодиодом
```
(+) → Резистор → Кнопка → Светодиод → (-)
```
**Результат:** Также работает!

**Вывод:** В последовательной цепи порядок компонентов не важен (кроме полярных — светодиод всегда в правильной полярности!).

### Эксперимент 2: Две кнопки последовательно
```
(+) → Кнопка1 → Кнопка2 → Резистор → Светодиод → (-)
```
**Результат:** Светодиод горит только если нажаты **ОБЕ** кнопки одновременно. Это логическое **И (AND)**.

### Эксперимент 3: Две кнопки параллельно

Если у вас нет второй кнопкой, украдите её у соседа.

```
        ┌─── Кнопка1 ───┐
(+) ────┤               ├──── Резистор → Светодиод → (-)
        └─── Кнопка2 ───┘
```
**Результат:** Светодиод горит если нажата **ЛЮБАЯ** кнопка. Это логическое **ИЛИ (OR)**.

## Возможные проблемы

### Светодиод не горит при нажатии кнопки

**Причина 1: Неправильная установка кнопки**
- **Решение:** Убедитесь, что кнопка установлена поперёк центральной канавки
- Попробуйте повернуть кнопку на 90°

**Причина 2: Плохой контакт**
- **Решение:** Проверьте, что все провода вставлены до упора
- Переставьте кнопку в другие ряды

**Причина 3: Неисправная кнопка**
- **Решение:** Попробуйте другую кнопку
- Проверьте кнопку мультиметром в режиме прозвонки

### Светодиод горит всегда (даже без нажатия)

**Причина 1: Кнопка установлена неправильно**
- Возможно, ножки кнопки попали в один и тот же ряд макетки
- **Решение:** Переставьте кнопку так, чтобы ножки были в разных рядах

**Причина 2: Замыкание в другом месте**
- **Решение:** Проверьте, нет ли случайных соединений проводами

### Светодиод иногда мигает сам по себе

**Причина:** Плохой контакт в макетке или дребезг кнопки
- **Решение:** Переставьте компоненты, убедитесь в надёжном контакте

## Что дальше?

Вы научились управлять цепью с помощью кнопки!

Теперь вы понимаете:
- Как работает механический выключатель
- Что такое замкнутая и разомкнутая цепь
- Как создавать интерактивное управление

Кнопка выглядит как мелкая плюмпочка, но на самом деле она может быть спрятана под доской/книгой/панелью/бумажкой, етц. Иногда полезно думать в другом контексте, например, создать схему настроенную на _размыкание_ цепи. В общем, кнопка это круто, теперь вы знаете как они "щёлкают". Постарайтесь когда вы нажимаете какую-то кнопку понять, а не такая же ли там кнопка внутри &mdash; обычно они "палятся" по характерном щелчку.

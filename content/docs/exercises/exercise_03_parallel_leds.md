# Упражнение 03: Два светодиода параллельно

**Вечер:** 1 (Основы)<br>
**Время:** 15 минут<br>
**Сложность:** <span class="difficulty-stars"><span class="filled">★</span><span class="empty">☆☆☆☆</span></span>

## Цель

Два светодиода горят одновременно от одного источника питания. Учимся параллельному соединению.

---

## Что учим

- **Параллельное соединение:** несколько компонентов подключены к одному источнику
- **Важно:** У каждого светодиода свой резистор!
- **Распределение тока:** ток делится между ветвями

---

## Необходимые компоненты

| Компонент | Количество | Примечание |
|-----------|------------|------------|
| Макетная плата с питанием | 1 | |
| Светодиоды (любой цвет) | 2 | Можно разных цветов |
| Резисторы 220Ω | 2 | Для каждого светодиода! |
| Провода для макетки | 4-6 | |

---

## Теория

### Что такое параллельное соединение?

При параллельном соединении компоненты подключены к **одним и тем же** точкам — к (+) и (-).

```
        ┌── Компонент 1 ──┐
(+) ────┤                 ├─── (-)
        └── Компонент 2 ──┘
```

**Ключевые свойства:**
- **Напряжение** на каждом компоненте **одинаковое** (равно напряжению источника)
- **Ток делится** между компонентами
- Каждый компонент работает **независимо** (если один сгорит, другой продолжит работать)

### Закон параллельного соединения

**Напряжение:**
```
V_total = V1 = V2 = V3 = ...
```
Все компоненты под одним напряжением.

**Ток:**
```
I_total = I1 + I2 + I3 + ...
```
Общий ток = сумма токов через каждый компонент.

**Сопротивление (для резисторов):**
```
1/R_total = 1/R1 + 1/R2 + 1/R3 + ...
```

### Почему каждому светодиоду нужен свой резистор?

**НЕПРАВИЛЬНО:**
```
      (+)
       │
    [220Ω] ← Один резистор на оба светодиода
       │
    ┌──┴──┐
   LED1  LED2
    └──┬──┘
       │
      (-)

ПРОБЛЕМА: Ток делится неравномерно!
Один светодиод может получить слишком много тока и сгореть.
```

**ПРАВИЛЬНО:**
```
        (+)
         │
    ┌────┴────┐
    │         │
  [220Ω]    [220Ω] ← Каждому светодиоду свой резистор
    │         │
   LED1      LED2
    │         │
    └────┬────┘
         │
        (-)

ПРАВИЛЬНО: Каждый светодиод защищён своим резистором.
```

### Расчёт тока от батарейки

Каждый светодиод потребляет ~15-20 мА.

- **Один светодиод:** 15 мА
- **Два светодиода параллельно:** 15 + 15 = 30 мА
- **Три светодиода:** 45 мА

**Батарейка 9V (Крона)** может дать 100-500 мА, так что для 2-5 светодиодов её хватит.

## Схема

### Текстовое описание
```
От (+) идут две ветки:
Ветка 1: Резистор 220Ω → Светодиод1 → (-)
Ветка 2: Резистор 220Ω → Светодиод2 → (-)
```

### ASCII-схема
```
           (+9V)
             │
     ┌───────┴───────┐
     │               │
   [220Ω]          [220Ω]
     │               │
    ╱│╲             ╱│╲
   ╱ │ ╲           ╱ │ ╲
  ────────         ────────
   LED1             LED2
     │               │
     └───────┬───────┘
             │
            (-)
```

### Схема на макетке
```
Шина (+) ═══════════════════════════════
           │              │
         [220Ω]         [220Ω]
           │              │
    Ряд 5: ●─LED1─●  ●─LED2─● (аноды)
    Ряд 6: ●─LED1─●  ●─LED2─● (катоды)
           │              │      жилые
           └──────┬───────┘      массивы
                  │
Шина (-) ═══════════════════════════════
```

## Пошаговая инструкция

### Шаг 1: Подготовка
1. **Отключите батарейку** от макетки
2. Очистите макетку или используйте новую область

### Шаг 2: Первая ветка (LED1)
1. Вставьте резистор 220Ω: одна ножка в **шину (+)**, вторая в **ряд 5**
2. Вставьте светодиод 1:
   - **Анод** (длинная ножка) в **ряд 5** (туда же, где резистор)
   - **Катод** (короткая ножка) в **ряд 6**
3. Провод от **ряда 6** (катод) к **шине (-)**

### Шаг 3: Вторая ветка (LED2)
1. Вставьте второй резистор 220Ω: одна ножка в **шину (+)**, вторая в **ряд 8**
2. Вставьте светодиод 2:
   - **Анод** в **ряд 8**
   - **Катод** в **ряд 9**
3. Провод от **ряда 9** к **шине (-)**

### Шаг 4: Проверка
1. Подключите батарейку
2. **Оба светодиода должны загореться одновременно!** 💡💡

---

## Что наблюдать

✓ **Оба светодиода горят одновременно**<br>
✓ **Яркость одинаковая** (если светодиоды одного типа)<br>
✓ **Если выдернуть один светодиод, второй продолжает гореть** &mdash; кстати, ярче или слабее?

## Эксперименты

### Эксперимент 1: Независимость веток
1. Аккуратно выньте **один светодиод** из макетки (не отключая питание)
2. **Результат:** Второй светодиод продолжает гореть
3. Вставьте обратно — оба снова горят

**Вывод:** Ветки работают **независимо**.

### Эксперимент 2: Три-четыре светодиода
Добавьте ещё 1-2 светодиода по тому же принципу:
- Каждому — свой резистор 220Ω
- Каждый от (+) к (-)

**Результат:** Все горят одновременно. Батарейка чуть быстрее разрядится.

### Эксперимент 3: Разные цвета
Используйте светодиоды разных цветов:
- Красный, зелёный, синий → получится RGB-подсветка!

### Эксперимент 4: Что будет без резистора?

**ОПАСНО! Делайте аккуратно и быстро!**

1. Уберите резистор из одной ветки
2. Подключите светодиод напрямую к (+) и (-)
3. **Результат:**
   - Светодиод ярко вспыхнет
   - Через 0.5-2 секунды **сгорит** (будет пахнуть)
   - Батарейка может нагреться

**Вывод:** Резистор — это не опция, а **необходимость**!

## Возможные проблемы

### Горит только один светодиод

**Причина 1: Неправильная полярность второго светодиода**
- **Решение:** Переверните второй светодиод

**Причина 2: Плохой контакт**
- **Решение:** Проверьте все соединения, переставьте компоненты

**Причина 3: Сгоревший светодиод**
- **Решение:** Замените светодиод на новый

### Оба светодиода горят, но с разной яркостью

**Причина 1: Разные типы светодиодов**
- Красные обычно ярче синих при одном токе
- **Это нормально** для разных цветов

**Причина 2: Разные резисторы**
- Проверьте, что оба резистора 220Ω (одинаковые полоски)

### Батарейка быстро разряжается

**Причина:** Много светодиодов потребляют много тока
- 1 светодиод: ~15 мА
- 5 светодиодов: ~75 мА
- Батарейка Крона ёмкостью ~500 мАч хватит на 500/75 ≈ 6-7 часов

**Решение:** Используйте блок питания или батареи большей ёмкости.

---

## Применение

Параллельное соединение используется везде:
- 🎄 **Гирлянды** (современные — каждый светодиод независим)
- 🚦 **Светофоры** (все огни от одного питания)
- 🎨 **Арт-объекты** (множество независимых источников света)
- 💻 **Компьютеры** (все компоненты от одного блока питания)

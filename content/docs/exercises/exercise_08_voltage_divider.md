## Теория

### Что такое делитель напряжения?

**Делитель напряжения** — это две последовательных сопротивления, которые делят входное напряжение пропорционально своим значениям.

```
     V_вход (например, 9V)
        │
      ┌─┴──┐
      │ R1 │
      └─┬──┘
        ├────→ V_выход (меньше V_вход)
      ┌─┴──┐
      │ R2 │
      └─┬──┘
        │
       GND

V_выход = V_вход × (R2 / (R1 + R2))
```

**Пример:**
```
V_вход = 9V
R1 = 10kΩ
R2 = 10kΩ

V_выход = 9V × (10kΩ / (10kΩ + 10kΩ))
        = 9V × (10/20)
        = 9V × 0.5
        = 4.5V
```

**Вывод:** Два одинаковых резистора делят напряжение пополам!

### Применение делителя с транзистором

Подавая напряжение с делителя на базу транзистора, мы можем **управлять его состоянием**:

```
Если V_выход > 0.7V → транзистор открывается → LED горит
Если V_выход < 0.7V → транзистор закрывается → LED не горит
```

### Потенциометр

**Потенциометр** — это переменный резистор с тремя выводами:

```
    Вывод 1 ●───┐
                │
    Ползунок ●──┼──→ Подвижный контакт
                │
    Вывод 3 ●───┘

    Между 1 и 3: полное сопротивление (10kΩ)
    Между 1 и 2: меняется от 0 до 10kΩ
    Между 2 и 3: меняется от 10kΩ до 0
```

**Использование как делитель:**
```
     (+9V)
       │
    1 ●───┐
          │ Потенциометр 10kΩ
    2 ●───┼───→ V_выход (от 0 до 9V)
          │
    3 ●───┘
       │
      GND
```

Вращая потенциометр, меняем **V_выход** от 0V до 9V!

### Фоторезистор (опционально)

**Фоторезистор** — резистор, сопротивление которого зависит от освещённости:

```
Яркий свет: R ≈ 1 kΩ
Темнота: R ≈ 1 MΩ
```

**Делитель с фоторезистором:**
```
     (+9V)
       │
    ┌──┴──┐
    │ 10kΩ│ R_фикс
    └──┬──┘
       ├───→ V_выход (к базе транзистора)
    ┌──┴──┐
    │ФотоР│ (1kΩ...1MΩ)
    └──┬──┘
       │
      GND

На ярком свету:
  R_фото ≈ 1kΩ (низкое)
  V_выход ≈ 9V × (1kΩ / 11kΩ) ≈ 0.8V
  → транзистор открыт слабо → LED горит тускло

В темноте:
  R_фото ≈ 1MΩ (высокое)
  V_выход ≈ 9V × (1MΩ / 1010kΩ) ≈ 8.9V
  → транзистор открыт полностью → LED горит ЯРКО!
```

**Вывод:** Чем темнее, тем ярче горит LED. Это работает как **автоматический ночник**!

> **Примечание:** Это упрощённый расчёт. Реальные значения зависят от конкретного фоторезистора. Можно поменять местами R_фикс и R_фото, чтобы получить обратную логику (светлее → LED ярче).

## Схема

### Вариант A: С потенциометром

```
        (+9V)
         │
      [220Ω]
         │
        LED
         │
         C
         │
    ┌────┴────┐
    │    Q    │  Транзистор
  B │         │ E
    └─┬─────┬─┘
      │     │
      │     └──→ (-)
      │
    ┌─┴──┐
  ◄─┤ POT├─► Потенциометр 10kΩ
    └─┬──┘
      │
     (+)
```

**Подключение потенциометра:**
- Вывод 1 → (+)
- Вывод 2 (средний, ползунок) → База транзистора
- Вывод 3 → GND

### Вариант B: С фоторезистором (автоматический ночник)

```
Силовая часть:    Делитель (управление):

    (+9V)             (+9V)
     │                 │
   [220Ω]            [10kΩ]
     │                 │
    LED                ├───→ к Базе
     │                 │
     C               [ФотоР]
     │                 │
  ┌──┴──┐             GND
  │  Q  │
B │     │ E
  └──┬──┘
     │
    (-)
```

**Логика:** Резистор 10kΩ и фоторезистор образуют делитель напряжения. Точка между ними подключается к базе транзистора.

## Пошаговая инструкция (Вариант A: Потенциометр)

### Начальное состояние
У вас должна быть схема из Упражнения 06 (транзистор + LED).

### Шаг 1: Отключение питания
1. **Отключите батарейку**

### Шаг 2: Установка потенциометра
1. Потенциометр имеет три вывода:
   - **Вывод 1** (крайний) → **шина (+)**
   - **Вывод 2** (средний) → **база транзистора**
   - **Вывод 3** (крайний) → **шина (-)**

> **Подсказка:** Если не уверены, какой вывод средний — смотрите на физическую форму потенциометра (средний обычно отдельно).

### Шаг 3: Проверка схемы
- Эмиттер транзистора → GND
- Коллектор → LED → (+)
- База ← ползунок потенциометра
- Потенциометр между (+) и (-)

### Шаг 4: Тестирование
1. Подключите батарейку
2. **Крутите потенциометр в одну сторону:** LED гаснет
3. **Крутите в другую сторону:** LED загорается
4. **Середина:** LED горит наполовину

## Пошаговая инструкция (Вариант B: Фоторезистор)

### Шаг 1: Отключение питания
1. **Отключите батарейку**
2. Уберите потенциометр (если был)

### Шаг 2: Делитель напряжения
1. **Резистор 10kΩ:**
   - Одна ножка → **шина (+)**
   - Вторая ножка → **ряд 15** (точка делителя)
2. **Фоторезистор:**
   - Одна ножка → **ряд 15** (туда же, где вторая ножка резистора)
   - Вторая ножка → **шина (-)**

### Шаг 3: Подключение к базе
1. Провод от **ряда 15** (точка делителя) к **базе транзистора**

### Шаг 4: Тестирование
1. Подключите батарейку
2. **На ярком свету:** LED горит тускло или почти не горит
   (R_фото = 1kΩ → V_база = 0.8V → транзистор открыт слабо)
3. **Накройте фоторезистор пальцем (темнота):** LED загорается ярко! 💡
   (R_фото = 1MΩ → V_база = 8.9V → транзистор открыт полностью)

**Логика:** Чем темнее, тем ярче LED. Это **автоматический ночник**!

> **Как изменить логику:** Поменяйте местами 10kΩ резистор и фоторезистор. Тогда будет наоборот: светлее → LED ярче.

## Эксперименты

### Эксперимент 1: Расчёт напряжения
С помощью мультиметра измерьте напряжение на базе транзистора при разных положениях потенциометра:
- Минимум: ~0V → транзистор закрыт
- Середина: ~4.5V → транзистор открыт
- Максимум: ~9V → транзистор полностью открыт

### Эксперимент 2: Разные делители
Попробуйте разные комбинации резисторов:

| R1 | R2 | V_выход (при 9V) | Состояние LED |
|----|----|----|-----|
| 1kΩ | 10kΩ | 8.2V | Ярко горит |
| 10kΩ | 10kΩ | 4.5V | Горит |
| 10kΩ | 1kΩ | 0.8V | Едва горит |
| 100kΩ | 1kΩ | 0.09V | Не горит |

### Эксперимент 3: "Умный" светильник
С фоторезистором создайте автоматический ночник:
- Днём (светло) → LED выключен
- Ночью (темно) → LED включается

### Эксперимент 4: Обратная логика
Поменяйте местами резистор и фоторезистор в делителе:
```
  (+) → Фоторезистор → точка A → Резистор 10kΩ → (-)
```
**Результат:** Обратное поведение (свет → LED гаснет, темно → LED горит)

## Возможные проблемы

### LED не реагирует на потенциометр

**Причина 1: Неправильное подключение потенциометра**
- **Решение:** Проверьте, что средний вывод идёт к базе, крайние — к (+) и (-)

**Причина 2: Потенциометр подключён боком**
- **Решение:** Попробуйте поменять крайние выводы местами

### LED не реагирует на свет (с фоторезистором)

**Причина 1: Резистор слишком большой или слишком маленький**
- **Решение:** Попробуйте разные номиналы (1kΩ, 10kΩ, 100kΩ)

**Причина 2: Фоторезистор и резистор в неправильном порядке**
- **Решение:** Поменяйте их местами

**Причина 3: Освещённость недостаточно меняется**
- **Решение:** Посветите фонариком или полностью накройте рукой

## Теория

### Что такое транзистор?

**Транзистор** — это полупроводниковый прибор, который может:
1. **Усиливать** слабый сигнал
2. Работать как **управляемый выключатель** (ключ)

Это один из самых важных компонентов в электронике. Без транзисторов не было бы компьютеров, смартфонов, радио!

**Аналогия:**
Представьте **водопроводный кран**:
- **Рукоятка** (маленькое усилие руки) = База
- **Поток воды** (большой поток) = Ток коллектор-эмиттер
- Маленькое усилие управляет большим потоком

### Типы транзисторов

Есть два основных типа биполярных транзисторов:
- **NPN** (мы используем) — самый распространённый
- **PNP** — работает "наоборот". Просто запомните, что такие тоже бывают.

В этом упражнении: **2N3904** или **BC547** — оба NPN-транзисторы.

### Три вывода транзистора

```
         C (Коллектор)
         │
         ▼
     ───────────
    │           │
B   │  ┌─────┐  │
───→│  │магия│  │
    │  └─────┘  │
     ───────────
         │
         ▼
         E (Эмиттер)
```

**Назначение выводов:**
- **Коллектор** (**C**, Collector): "Вход" большого тока
- **Эмиттер** (**E**, Emitter):** "Выход" большого тока
- **База** (**B**, Base):** "Управление" — маленький ток сюда управляет большим током через C→E

**Физический смысл:**
- Эмиттер **излучает** (emits) электроны
- Коллектор **собирает** (collects) электроны
- База **управляет** потоком электронов

### Распиновка 2N3904 / BC547

**ВАЖНО:** Разные транзисторы имеют разную распиновку! Всегда смотрите даташит. Сжечь транзистор очень легко, легче чем светодиод.

**2N3904 (распространённый у англосаксов):**
```
     Вид СНИЗУ (ножками к себе):
       ___
      ╱   ╲
     │  O  │  ← Плоская сторона сверху
     │     │
     └──┬──┘
     │  │  │
     E  B  C

   (слева направо: E-B-C)
```

**BC547 (распространённый в Европе/России):**
```
     Вид СНИЗУ (ножками к себе):
       ___
      ╱   ╲
     │  O  │  ← Плоская сторона сверху
     │     │
     └──┬──┘
     │  │  │
     C  B  E

   (слева направо: C-B-E)
```

> **Важно:** Если схема не работает, первым делом проверьте распиновку транзистора! Найдите даташит в интернете.

В целом, самое главное помнить что база всегда на центральной ножка (если, конечно, это не олдовый КТ-315)

Транзисторы в целом отличаются друг от друга "скоростью" срабатывания (важно для радио и высокочастотных применений), силой тока который они могут пропускать через себя и напряжением которые они могут держать. В для подавляющего большинства задач art engineering нам можно не углубляться в детали. Если вы вдруг херачите катушки Тесла то да, стоит задуматься и об этом (погуглите, что такое катушки Тесла и не херачьте их пока не будете готовы, спасибо)

### Как работает NPN-транзистор

**Условия открытия транзистора:**
1. На базе должно быть напряжение **выше**, чем на эмиттере (~0.6-0.7V для кремниевого)
2. Через базу должен течь **небольшой ток** (обычно 0.01-1 мА)

**Два состояния:**

**ЗАКРЫТ (выключен):**
```
Ток базы = 0
→ Транзистор не проводит
→ Ток C→E = 0
→ Светодиод не горит
```

**ОТКРЫТ (включен):**
```
Ток базы > 0 (например, 0.1 мА)
→ Транзистор проводит
→ Ток C→E = большой (например, 20 мА)
→ Светодиод горит!
```

### Коэффициент усиления (hFE или β)

_Обычно_ транзистор можно привести к аналогичной эквивалентной схеме из нескольких резисторов с волшебными сопротивлениями. Нам важно знать только основные выводы из этих моделей. Один из таких важных элементов это коэффициент усиления.

**Формула:**
```
I_коллектора = hFE × I_базы

hFE (или β) — коэффициент усиления тока
Обычно: 100-300 для 2N3904/BC547
```

**Пример:**
- I_базы = 0.1 мА
- hFE = 100
- I_коллектора = 100 × 0.1 мА = 10 мА ← достаточно для светодиода!

**Вывод:** Маленький ток базы управляет большим током коллектора!

{{% details "❓ Вопрос на засыпку: как узнать коэффициент усиления?" %}}
Ответ: подсмотреть в **даташите** (datasheet) конкретного транзистора. Там обычно указан параметр **hFE** или **β** (бета).
{{% /details %}}

### Зачем резистор на базе?

**Без резистора:**
```
(+) → База транзистора → (очень большой ток!) → ВЗРЫВ
```

Транзистор работает почти как диод между базой и эмиттером. Без резистора через базу пойдёт огромный ток → транзистор сгорит.

**С резистором:**
```
(+) → Резистор 10kΩ → База → Эмиттер → (-)

I_базы = (9V - 0.7V) / 10kΩ ≈ 0.8 мА ← безопасно
```

Резистор 10kΩ ограничивает ток базы до безопасного значения.

## Схема

### Текстовое описание
```
Батарея (+) → Резистор 220Ω → Светодиод → Коллектор (C)
Транзистор 2N3904
Эмиттер (E) → Батарея (-)

Управление:
Батарея (+) → Резистор 10kΩ → Кнопка → База (B)
```

### ASCII-схема
```
        (+9V)
         │
      [220Ω]  ← Резистор для LED
         │
        ╱│╲
       ╱ │ ╲  ← Светодиод
      ────────
         │
         C (Коллектор)
         │
    ┌────┴────┐
    │    Q    │  Транзистор NPN
    │ 2N3904  │
  B │         │ E
    └─┬──────┬┘
      │      │
      │      └──→ (-)
      │
   [10kΩ]  ← Резистор для базы
      │
     ┌┴┐
     │○│  ← Кнопка
     └┬┘
      │
     (+)
```

### Схема на макетке (BC547)
```
             Левая     ║     Правая
             сторона   ║     сторона
Шина (+) ══════●═══════╬═════●═══════
               │       ║     │
             [220Ω]    ║   [10kΩ]
               │       ║     │
  Ряд 5: ●─────┴───●   ║     ●─┐
           (анод LED)  ║     │ │
  Ряд 6:           │   ║  [КНОПКА]
                   │   ║     │ │
  Ряд 7: ●─────────┴───●─────●─┘
         (катод LED + C)     │
  Ряд 8: ●───(B)───────╬─────●──────┐
  Ряд 9: ●───(E)       ║            │
         │             ║            │
Шина (-) ══════●═══════╬════════════┘
```

**Распиновка BC547 (вид снизу, ножками к себе):**
- Ряд 7: **C** (Коллектор) — левая ножка
- Ряд 8: **B** (База) — центральная ножка
- Ряд 9: **E** (Эмиттер) — правая ножка

**Пояснение:**
- **Транзистор BC547:** три ножки в рядах 7-8-9 на левой стороне (распиновка C-B-E)
- **LED:** анод в ряду 5, катод в ряду 7 вместе с коллектором
- **Резистор 220Ω:** от шины (+) к ряду 5 (анод LED)
- **Кнопка:** поперёк канавки на правой стороне. Верхняя ножка через резистор 10kΩ к (+), нижняя — проводом к базе (ряд 8)

> **Важно:** Если у вас 2N3904 (распиновка E-B-C), то эмиттер и коллектор меняются местами — вставляйте транзистор наоборот!

Проверьте то что вы собрали, в первую очередь ориентируясь на описание и на ASCII-схему выше.

## Пошаговая инструкция

### Шаг 0: Определение распиновки
1. **Найдите маркировку на транзисторе** (2N3904, BC547, и т.д.)
2. **Найдите даташит** в интернете: "2N3904 pinout"
3. **Запомните:** E-B-C (2N3904) или C-B-E (BC547)

### Шаг 1: Подготовка
1. **Отключите батарейку**
2. Очистите макетку

### Шаг 2: Установка транзистора
1. Установите транзистор **поперёк центральной канавки**:
   - Эмиттер (E) — в ряд 9
   - База (B) — в ряд 8
   - Коллектор (C) — в ряд 7

> **Подсказка:** Держите транзистор плоской стороной к себе, ножками вниз, и вставляйте в макетку слева направо по даташиту.

### Шаг 3: Эмиттер → Земля
1. Провод от **ряда 9 (эмиттер)** к **шине (-)**

### Шаг 4: Светодиод и резистор
1. Резистор 220Ω: одна ножка в **шину (+)**, вторая в **ряд 5**
2. Светодиод:
   - **Анод** в **ряд 5** (с резистором)
   - **Катод** в **ряд 7** (с коллектором транзистора)

### Шаг 5: Кнопка и резистор базы
1. Установите кнопку в макетку (поперёк канавки)
2. Резистор 10kΩ: одна ножка в **шину (+)**, вторая к одной ножке кнопки
3. Провод от второй ножки кнопки к **ряду 8 (база транзистора)**

### Шаг 6: Проверка схемы
Проверьте:
- Эмиттер (E) → земля (-)
- Коллектор (C) → светодиод → (+)
- База (B) ← кнопка ← резистор 10kΩ ← (+)

### Шаг 7: Включение
1. Подключите батарейку
2. **Не нажимая кнопку:** светодиод НЕ горит
3. **Нажмите кнопку:** светодиод загорается! 💡

---

## Что наблюдать

✓ **Без нажатия кнопки:** светодиод не горит (транзистор закрыт)<br>
✓ **При нажатии:** светодиод ярко горит (транзистор открыт)<br>
✓ **Мгновенное переключение** типа


{{% details "Резонный вопрос &mdash; а нахрена транзистор если и до этого можно было просто по кнопке включать? :thinking:" %}}
На деле тут кнопка это условность, думайте о ней как о "поступил внешний сигнал". Этот сигнал может приходить от фоторезистора, другой системы, датчика, и так далее. Справедливости ради и сам LED тоже условность и на его месте мог бы быть другой прибор/устройство/механизм.
{{% /details %}}

**Что происходит:**
1. **Кнопка нажата:** Ток течёт через резистор 10kΩ на базу → транзистор открывается → большой ток через C→E → светодиод горит
2. **Кнопка отпущена:** Ток базы = 0 → транзистор закрывается → светодиод гаснет

## Эксперименты

### Эксперимент 1: Измерение усиления

Измерьте токи (если есть мультиметр):
- Ток базы: ~0.8 мА (через резистор 10kΩ)
- Ток коллектора: ~20 мА (через светодиод)
- Усиление: 20 / 0.8 ≈ 25 раз

> **Примечание:** Усиление зависит от тока и может быть меньше номинального hFE.

### Эксперимент 2: Разные резисторы базы

Попробуйте заменить 10kΩ на другие:

| Резистор базы | Ток базы | Состояние транзистора |
|---------------|----------|----------------------|
| 1kΩ | ~8 мА | Открыт полностью (яркий LED) |
| 10kΩ | ~0.8 мА | Открыт (яркий LED) |
| 100kΩ | ~0.08 мА | Открыт частично (тусклый LED) |
| 1MΩ | ~0.008 мА | Почти закрыт (LED еле горит) |

**Вывод:** Транзистор работает даже с очень маленьким током базы!

### Эксперимент 3: Без резистора базы

**ОПАСНО! Делайте быстро!**
1. Уберите резистор 10kΩ, подключите кнопку напрямую к (+) и базе
2. Нажмите кнопку
3. **Результат:** Светодиод горит, но через базу течёт слишком большой ток → транзистор нагревается → может сгореть

**Вывод:** Резистор базы обязателен!

### Эксперимент 4: Управление несколькими светодиодами

Подключите параллельно 2-3 светодиода (каждый со своим резистором 220Ω) к коллектору:
```
        (+)
         │
    ┌────┴────┐
  [220Ω]    [220Ω]
    │         │
   LED1      LED2
    │         │
    └────┬────┘
         │
         C (транзистор)
```

**Результат:** Одна кнопка (малый ток базы) управляет несколькими светодиодами (большой ток коллектора)!

## Возможные проблемы

### Светодиод не горит при нажатии кнопки

**Причина 1: Неправильная распиновка транзистора**
- **Решение:** Проверьте даташит, переставьте транзистор правильно

**Причина 2: Транзистор вставлен наоборот (E и C перепутаны)**
- **Решение:** Переверните транзистор

**Причина 3: Неправильная полярность светодиода**
- **Решение:** Переверните светодиод

**Причина 4: Плохой контакт**
- **Решение:** Переставьте транзистор, убедитесь, что ножки вставлены до упора

**Причина 5: Сгоревший транзистор**
- **Решение:** Попробуйте другой транзистор

### Светодиод горит всегда (даже без нажатия кнопки)

**Причина 1: Резистор базы отсутствует или слишком маленький**
- Ток утечки может открыть транзистор
- **Решение:** Используйте 10kΩ

**Причина 2: Статическое электричество**
- **Решение:** Коснитесь эмиттера и базы транзистора пальцем (разрядите)

### Светодиод горит очень тускло при нажатии

**Причина 1: Резистор базы слишком большой**
- Мало тока базы → транзистор открыт частично
- **Решение:** Используйте меньший резистор (1-10kΩ)

**Причина 2: Слабая батарейка**
- **Решение:** Замените батарейку

### Транзистор нагревается

**Причина:** Слишком большой ток (нет резистора на базе или слишком много нагрузки на коллекторе)
- **Решение:** Отключите питание, проверьте схему

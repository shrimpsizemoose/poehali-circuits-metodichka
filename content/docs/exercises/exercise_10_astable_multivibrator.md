## Цель

Два светодиода мигают **по очереди**: первый горит → гаснет → второй горит → гаснет → повтор. Симметричная схема на двух транзисторах с взаимной блокировкой.

---

## Что учим

- **Астабильный мультивибратор** — классическая схема
- **Симметричная схема** — зеркальное отражение
- **Взаимная блокировка** — транзисторы переключают друг друга
- **Перекрёстные связи** — выход одного управляет другим

## Теория

### Что такое мультивибратор?

**Мультивибратор** — схема с **двумя устойчивыми состояниями**, которая переключается между ними.

**Типы:**
- **Астабильный** (наш случай): Переключается сам, нет стабильных состояний
- **Моностабильный**: Одно стабильное состояние, возвращается после импульса
- **Бистабильный**: Два стабильных состояния (триггер, память)

### Принцип работы астабильного мультивибратора

**Идея:** Два транзистора **по очереди** открываются и закрываются.

```
Состояние 1:
  Q1 открыт → LED1 горит
  Q2 закрыт → LED2 не горит

Через время T1 → переключение

Состояние 2:
  Q1 закрыт → LED1 не горит
  Q2 открыт → LED2 горит

Через время T2 → переключение обратно
```

### Перекрёстные связи

Ключ к работе — **перекрёстные связи через конденсаторы**:

```
Коллектор Q1 ──┤├──→ База Q2
Коллектор Q2 ──┤├──→ База Q1
```

Когда Q1 переключается, он через конденсатор влияет на Q2, и наоборот!

### Последовательность событий (один цикл)

**Пусть Q1 открыт, Q2 закрыт:**

1. **Q1 открыт:**
   - Коллектор Q1 ≈ 0V (близко к земле)
   - LED1 горит
   - Конденсатор C1: плюс (+) на коллекторе Q1 (~0V), минус (-) на базе Q2
   - База Q2 имеет отрицательное напряжение (ниже эмиттера) → Q2 закрыт

2. **Конденсатор C1 разряжается:**
   - Заряд утекает через резистор R4
   - Напряжение на базе Q2 медленно растёт
   - Время разряда: T ≈ 0.7 × R4 × C1

3. **Q2 начинает открываться:**
   - База Q2 достигла ~0.7V
   - Q2 открывается
   - Коллектор Q2 падает к 0V
   - LED2 загорается

4. **Лавинное переключение:**
   - Падение напряжения на коллекторе Q2 передаётся через C2 на базу Q1
   - База Q1 резко падает → Q1 закрывается
   - LED1 гаснет
   - **Состояния поменялись!**

5. **Теперь Q2 открыт, Q1 закрыт** → процесс повторяется зеркально

## Схема

### Упрощённая схема
```
         (+9V)
           │
      ┌────┴────┐
      │         │
    [R1]      [R2]
    1kΩ        1kΩ
      │         │
     LED1      LED2
      │         │
      C1        C2  ← Коллекторы
      │         │
     Q1        Q2  ← Транзисторы BC547
      │         │
      E1────────E2  ← Эмиттеры соединены
           │
          (-)

Ключевые связи:
1. Базы подтянуты к (+):
   (+) ──[R3=10kΩ]── База Q1
   (+) ──[R4=10kΩ]── База Q2

2. Перекрёстные конденсаторы:
   Коллектор Q1 ──[C1=10µF(+) (-)]── База Q2
   Коллектор Q2 ──[C2=10µF(+) (-)]── База Q1
```

**Принцип:** Каждый транзистор управляет другим через конденсатор!

### Детальная схема
```
        (+9V)                    (+9V)
         │                        │
    ┌────┴────┐              ┌────┴────┐
    │         │              │         │
  [R1]      [R3]           [R2]      [R4]
  1kΩ       10kΩ           1kΩ       10kΩ
    │         │              │         │
   LED1       ├─────────────────────── База Q2
    │         │              │         │
    C1────────┼──[C1]─(-)────┤         │
    │         │  10µF        │         │
  ┌─┴─┐       │            ┌─┴─┐       │
  │Q1 │       │            │Q2 │       │
  └─┬─┘       │            └─┬─┘       │
    E1────────┼──────────────E2        │
    │         │              │         │
    │         └────[C2]─(+)──┘         │
    │             10µF                 │
    │                                  │
   (-)            База Q1 ─────────────┘

Конденсаторы (полярность!):
- C1: (+) на коллекторе Q1, (-) на базе Q2
- C2: (+) на коллекторе Q2, (-) на базе Q1
```

**Подсказка:** Это сложная схема с перекрёстными связями. Рекомендую загуглить "astable multivibrator schematic" — картинки помогают понять топологию!

## Пошаговая инструкция

### Шаг 0: Подготовка
1. **Отключите батарейку**
2. Очистите макетку
3. Разложите все компоненты перед собой

### Шаг 1: Транзисторы
1. **Q1** (первый транзистор):
   - Эмиттер (E) → ряд 9
   - База (B) → ряд 8
   - Коллектор (C) → ряд 7

2. **Q2** (второй транзистор):
   - Эмиттер (E) → ряд 12
   - База (B) → ряд 11
   - Коллектор (C) → ряд 10

### Шаг 2: Эмиттеры к земле
1. Соедините **эмиттеры Q1 и Q2 проводом**
2. Провод от эмиттеров к **шине (-)**

### Шаг 3: Коллекторные нагрузки (LED1 + R1)
1. **Для Q1:**
   - Резистор 1kΩ (R1): шина (+) → ряд 5
   - LED1: ряд 5 (анод) → ряд 7 (катод, к коллектору Q1)

2. **Для Q2:**
   - Резистор 1kΩ (R2): шина (+) → ряд 3
   - LED2: ряд 3 (анод) → ряд 10 (катод, к коллектору Q2)

### Шаг 4: Базовые резисторы
1. **R3 (10kΩ):** шина (+) → ряд 8 (база Q1)
2. **R4 (10kΩ):** шина (+) → ряд 11 (база Q2)

### Шаг 5: Перекрёстные конденсаторы (ВНИМАНИЕ!)

**C1 (от коллектора Q1 к базе Q2):**
1. **Плюс (+)** конденсатора → ряд 7 (коллектор Q1)
2. **Минус (-)** конденсатора → ряд 11 (база Q2)

**C2 (от коллектора Q2 к базе Q1):**
1. **Плюс (+)** конденсатора → ряд 10 (коллектор Q2)
2. **Минус (-)** конденсатора → ряд 8 (база Q1)

> **КРИТИЧНО:** Плюс конденсатора к коллектору, минус к базе противоположного транзистора!

### Шаг 6: Проверка
Проверьте все соединения:
- Эмиттеры обоих Q → GND
- Коллекторы → LED → (+) через 1kΩ
- Базы → (+) через 10kΩ
- C1: C_Q1(+) → B_Q2(-)
- C2: C_Q2(+) → B_Q1(-)

### Шаг 7: Включение!
1. **Подключите батарейку**
2. **Светодиоды должны мигать по очереди!** 🎉✨

## Возможные проблемы

### Оба светодиода горят постоянно

**Причина 1: Неправильная полярность конденсаторов**
- **Решение:** Плюс к коллектору, минус к базе (противоположного транзистора!)

**Причина 2: Конденсаторы слишком маленькие**
- **Решение:** Используйте минимум 10µF

**Причина 3: Резисторы перепутаны**
- **Решение:** Проверьте номиналы (1kΩ для LED, 10kΩ для баз)

### Оба светодиода не горят

**Причина 1: Нет питания**
- **Решение:** Проверьте батарейку, шины питания

**Причина 2: Эмиттеры не соединены**
- **Решение:** Соедините эмиттеры проводом

**Причина 3: Неправильная распиновка транзисторов**
- **Решение:** Проверьте даташит

### Только один светодиод мигает

**Причина 1: Один конденсатор не подключён или неправильной полярности**
- **Решение:** Проверьте оба конденсатора

**Причина 2: Один транзистор неисправен**
- **Решение:** Замените транзистор

### Мигает очень быстро (не видно)

**Причина:** RC слишком мало
- **Решение:** Увеличьте конденсаторы (100µF) или резисторы (100kΩ)

### Неравномерное мигание

**Причина:** Разные номиналы компонентов
- **Решение:** Используйте одинаковые RC для симметрии

## Расчёт частоты

**Период одного полуцикла:**
```
T_половина = 0.7 × R_base × C

R_base = 10kΩ = 10,000 Ом
C = 10µF = 0.00001 Ф

T_половина = 0.7 × 10,000 × 0.00001 = 0.07 секунды
```

**Полный период (оба LED по разу):**
```
T_полный = 2 × T_половина = 0.14 секунды
```

**Частота:**
```
f = 1 / T_полный = 1 / 0.14 ≈ 7 Гц
```

Каждый LED мигает 7 раз в секунду.

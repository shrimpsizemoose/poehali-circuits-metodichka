# Упражнение 07: Сенсорная кнопка

**Вечер:** 2 (Транзисторы)<br>
**Время:** 15-20 минут<br>
**Сложность:** <span class="difficulty-stars"><span class="filled">★★</span><span class="empty">☆☆☆</span></span>

---

## Цель

Светодиод загорается от прикосновения пальцем к двум проводкам. Создаём сенсорный датчик _своими руками!_

---

## Что учим

- **Высокое сопротивление базы** делает транзистор очень чувствительным
- **Тело человека проводит ток** (слабо, но достаточно)
- **Принцип сенсорных кнопок**

---

## Необходимые компоненты

| Компонент | Количество | Примечание |
|-----------|------------|------------|
| Схема из упражнения 06 | 1 | Транзистор + LED |
| Резистор 100kΩ или 1MΩ | 1 | Вместо 10kΩ |
| Два кусочка провода | 2 | 5-10 см |

---

## Теория

### Сопротивление тела человека

**Сопротивление между пальцами:** 100 кОм - 1 МОм (зависит от влажности кожи)

При сухих руках:
```
R_тела ≈ 1 МОм
```

При влажных руках:
```
R_тела ≈ 100 кОм
```

### Почему нужен большой резистор базы?

С обычным резистором 10kΩ:
```
Последовательно: 10kΩ + 1MΩ (тело) = 1010 кΩ
Ток базы: 9V / 1010kΩ ≈ 0.009 мА → слишком мало!
```

С резистором 100kΩ или 1MΩ:
```
Последовательно: 100kΩ + 1MΩ (тело) = 1100 кΩ
Ток базы: 9V / 1100kΩ ≈ 0.008 мА → достаточно для чувствительного транзистора!
```

Или вообще без резистора (только сопротивление тела):
```
Ток базы: 9V / 1MΩ ≈ 0.009 мА → работает!
```

### Принцип работы

1. **Пальцы не касаются проводов:** Цепь базы разомкнута → транзистор закрыт → LED не горит
2. **Пальцы касаются обоих проводов:** Тело замыкает цепь базы → небольшой ток через базу → транзистор открывается → LED горит!

## Схема

### Модификация схемы из упр. 06

**Было (с кнопкой):**
```
(+) → [10kΩ] → Кнопка → База
```

**Стало (сенсорная кнопка):**
```
(+) → [100kΩ] → Провод1 (сенсор 1)
                    │
                 (палец)
                    │
               Провод2 (сенсор 2) → База
```

Когда палец касается обоих проводов, он замыкает цепь через сопротивление тела (~1MΩ).

### ASCII-схема
```
        (+9V)
         │
      [220Ω]
         │
        LED
         │
         C
         │
    ┌────┴────┐
    │    Q    │  Транзистор
  B │         │ E
    └────┬────┘
         │
         └──→ (-)

Цепь управления:

    (+) ─────[100kΩ]──── ●  Сенсор 1 (провод в воздухе)
                          │
                        (палец ~1MΩ)
                          │
    База ←────────────── ●  Сенсор 2 (провод в воздухе)
```

## Пошаговая инструкция

### Начальное состояние
У вас должна быть собрана схема из Упражнения 06 (транзистор + LED + кнопка).

### Шаг 1: Отключение питания
1. **Отключите батарейку**

### Шаг 2: Замена резистора базы
1. Выньте резистор **10kΩ** из схемы управления базой
2. Вставьте резистор **100kΩ** (коричневый-чёрный-жёлтый) или **1MΩ** (коричневый-чёрный-зелёный)

### Шаг 3: Замена кнопки на сенсорные провода
1. **Выньте кнопку** полностью
2. Возьмите два провода длиной **5-10 см** (зачистите концы)
3. Подключите провода:
   - **Сенсор 1 (провод 1):** один конец вставьте в точку **после резистора 100kΩ** (тот же ряд, где раньше была нижняя ножка кнопки). Второй конец оставьте **свободным в воздухе**
   - **Сенсор 2 (провод 2):** один конец вставьте в **ряд 8 (база транзистора)**. Второй конец оставьте **свободным в воздухе**

> **Важно:** Свободные концы проводов должны быть рядом, но **НЕ касаться друг друга**!

### Шаг 4: Проверка схемы
Убедитесь:
- Резистор 100kΩ между шиной (+) и сенсором 1
- Сенсор 2 подключен к базе транзистора (ряд 8)
- Оба сенсорных провода торчат в воздухе на расстоянии 1-2 см друг от друга

### Шаг 5: Тестирование
1. Подключите батарейку
2. **Не касайтесь проводов:** LED не горит ✓
3. **Коснитесь пальцами обоих проводов одновременно:** LED загорается! ✨
4. **Отпустите:** LED гаснет

## Эксперименты

### Эксперимент 1: Влажность рук
- **Сухие руки:** LED горит тускло или не горит
- **Лизните палец:** LED горит ярко!
- **Влажные руки (после мытья):** очень чувствительно

**Вывод:** Влажность кожи уменьшает сопротивление → больше ток базы → ярче LED.

### Эксперимент 2: Разные расстояния между сенсорами

Попробуйте расположить свободные концы двух сенсорных проводов на разных расстояниях:

- **1-2 см:** можно легко коснуться обоих проводов **одним пальцем** → работает отлично
- **5 см:** нужно использовать **два пальца** (или растянуть один) → работает
- **10 см и больше:** сложно дотянуться до обоих одновременно, может потребоваться две руки

**Вывод:** Чем ближе провода друг к другу, тем удобнее ими пользоваться. Оптимально: 1-2 см между концами.

### Эксперимент 3: Сенсорная площадка
Вместо двух проводов приклейте к картону два кусочка фольги (расстояние 1-2 см):
```
┌────────────────┐
│  Картон        │
│                │
│  ▓▓▓   ▓▓▓     │ ← Фольга
│   │     │      │
│   └─────┴──────┼──→ к схеме
└────────────────┘
```

Касание пальцем области между фольгой включает LED!

_Ахаха_. Ладно, на самом деле вот это вот "приклейте" это чуть ли не сложнее чем вся схема. Приклеить к фольге проводок не так-то просто! Как и фольгу. Короче, тут надо будет повозиться. Удачи. Возьмите на худой конец скотч по краям, но убедитесь что у фольги есть контакт с вашими проводами &mdash; без этого ничего не заработает.

### Эксперимент 4: Без резистора
Попробуйте убрать резистор 100kΩ совсем (только сопротивление тела):
- **Результат:** Работает! Ток через базу ≈ 9V / 1MΩ = 0.009 мА

> **Примечание:** Без резистора схема более чувствительная, но менее стабильная (статическое электричество может помешать).

### Эксперимент 5: Дистанционное управление
Один провод держите в руке, второй положите на стол:
- Касание второго провода → LED горит
- Ваше тело работает как "антенна"!

## Возможные проблемы

### Светодиод не загорается при касании

**Причина 1: Резистор слишком маленький**
- **Решение:** Используйте 100kΩ или больше

**Причина 2: Сухие руки**
- **Решение:** Смочите пальцы или лизните их

**Причина 3: Неправильная схема**
- **Решение:** Проверьте, что провода идут от (+) через резистор к базе

### Светодиод горит всегда (даже без касания)

**Причина 1: Провода касаются друг друга**
- **Решение:** Разведите провода

**Причина 2: Резистор слишком большой + влажность воздуха**
- **Решение:** Используйте 100kΩ вместо 1MΩ

**Причина 3: Статическое электричество**
- **Решение:** Коснитесь корпуса транзистора, чтобы разрядить

### Очень низкая чувствительность

**Причина:** Батарейка разряжена или резистор слишком маленький
- **Решение:** Замените батарейку, используйте резистор 1MΩ

## Применение

Сенсорные датчики используются:

- **Сенсорные кнопки** на бытовой технике
- **Сенсорные экраны** (ёмкостные)
- **Музыкальные инструменты** (например, терменвокс)
- **Интерактивные арт-объекты** (касание объекта активирует свет/звук)
- **Датчики приближения**

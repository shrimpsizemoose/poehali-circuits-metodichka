## Теория

### Что такое генератор?

**Генератор** (осциллятор) — это схема, которая создаёт **периодические колебания** без внешнего управления.

В отличие от предыдущих схем (кнопка → LED), генератор **сам переключается** между состояниями:
```
LED горит → LED гаснет → LED горит → LED гаснет → ...
```

### Принцип положительной обратной связи

**Обратная связь** — когда выход схемы влияет на вход.

**Отрицательная ОС:** Выход уменьшает вход → стабилизация
**Положительная ОС:** Выход усиливает вход → лавина, переключение

```
       ┌──────────────┐
  Вход │              │Выход
  ────►│  Усилитель   ├────►
       │              │
       └──────┬───────┘
              │
              └─────────► Обратно на вход!
```

При положительной ОС система **неустойчива** → переключается сама.

### Релаксационный генератор

**Принцип работы:**
1. Конденсатор **заряжается** через резистор
2. Когда напряжение достигает порога → транзистор **открывается**
3. Конденсатор быстро **разряжается** через транзистор
4. Транзистор **закрывается**
5. Цикл повторяется!

```
Напряжение на конденсаторе:

      ╱╲    ╱╲    ╱╲
     ╱  ╲  ╱  ╲  ╱  ╲
────╱────╲╱────╲╱────╲───► Время
    │    │    │    │
  Заряд Разряд
```

### Расчёт частоты

Частота мигания зависит от **постоянной времени RC**:

```
T ≈ 0.7 × R × C

T — период (секунды)
R — сопротивление (Ом)
C — ёмкость (Фарады)
```

**Пример:**
```
R = 100kΩ = 100,000 Ом
C = 10µF = 0.00001 Ф

T = 0.7 × 100,000 × 0.00001 = 0.7 секунды
Частота = 1/T ≈ 1.4 Гц (1.4 мигания в секунду)
```

## Схема

### ASCII-схема
```
        (+9V)
         │
         ├────[100kΩ]────┐
         │               │
       [1kΩ]          [10µF]
         │            +  │  -
        LED              │
         │               │
         C ──────────────┤
         │               │
    ┌────┴────┐          B
    │    Q    │
    │  BC547  │
    └────┬────┘
         E
         │
        (-)
```

**Ключевая идея:**
- Резистор 100kΩ подтягивает базу к (+) → транзистор постепенно открывается
- Конденсатор 10µF между **коллектором** и **базой** создаёт обратную связь
- Когда транзистор открывается, напряжение на коллекторе падает → конденсатор тянет базу вниз → транзистор закрывается!

### Детальная схема
```
        (+9V)                     (+9V)
         │                         │
         │                      [100kΩ] ← Подтяжка базы
         │                         │
       [1kΩ] ← Нагрузка            │
         │                         │
        LED                        ├─────── База (B)
         │                         │
         │                      [10µF]
         C ← Коллектор          +  │  -
         │                         │
         └─────────────────────────┘

    ┌────┴────┐
    │    Q    │  Транзистор BC547
    │  BC547  │  (распиновка C-B-E)
    └────┬────┘
         E ← Эмиттер
         │
        (-)
```

## Пошаговая инструкция

### Шаг 1: Подготовка
1. **Отключите батарейку**
2. Очистите макетку

### Шаг 2: Установка транзистора
1. Вставьте транзистор в макетку (как обычно):
   - Эмиттер (E) → ряд 9
   - База (B) → ряд 8
   - Коллектор (C) → ряд 7

### Шаг 3: Эмиттер к земле
1. Провод от ряда 9 (эмиттер) к шине (-)

### Шаг 4: Коллекторная нагрузка (LED + резистор)
1. Резистор 1kΩ: одна ножка в шину (+), вторая в ряд 5
2. Светодиод:
   - Анод в ряд 5 (с резистором)
   - Катод в ряд 7 (с коллектором)

### Шаг 5: Базовый резистор
1. Резистор 100kΩ:
   - Одна ножка в **шину (+)**
   - Вторая в **ряд 8 (база транзистора)**

### Шаг 6: Конденсатор обратной связи (ВНИМАНИЕ!)
1. Конденсатор 10µF:
   - **Плюс (+)** (длинная ножка) в **ряд 7 (коллектор)**
   - **Минус (-)** (короткая ножка) в **ряд 8 (база)**

> **КРИТИЧНО:** Плюс конденсатора к коллектору, минус к базе!

### Шаг 7: Проверка
Проверьте все соединения:
- Эмиттер → GND
- Коллектор → LED → (+) через 1kΩ
- База → (+) через 100kΩ
- База ← Конденсатор (минус) → Коллектор (плюс)

### Шаг 8: Включение
1. Подключите батарейку
2. **Светодиод должен мигать!** ✨

## Возможные проблемы

### Светодиод не мигает (горит постоянно)

**Причина 1: Неправильная полярность конденсатора**
- **Решение:** Переверните конденсатор (плюс к коллектору!)

**Причина 2: Резистор слишком маленький**
- **Решение:** Используйте 100kΩ для базы

**Причина 3: Конденсатор не подключён к коллектору**
- **Решение:** Проверьте, что конденсатор между коллектором и базой

### Светодиод не мигает (не горит вообще)

**Причина 1: Неправильная схема**
- **Решение:** Проверьте все соединения по схеме

**Причина 2: Неисправный транзистор или конденсатор**
- **Решение:** Попробуйте другие компоненты

**Причина 3: Базовый резистор слишком большой**
- **Решение:** Попробуйте меньший номинал (10kΩ - 100kΩ)

### Светодиод мигает очень быстро (не видно глазом)

**Причина:** Слишком маленький RC
- **Решение:** Увеличьте конденсатор (100µF) или резистор (1MΩ)

### Светодиод иногда "зависает"

**Причина:** Схема на грани устойчивости
- **Решение:** Попробуйте другой транзистор, убедитесь в хороших контактах

## Как это работает (подробно)

**Цикл работы:**

1. **Начальное состояние:**
   - Конденсатор разряжен
   - База подтянута к (+) через 100kΩ
   - Транзистор начинает открываться

2. **Транзистор открывается:**
   - Ток течёт через коллектор → LED горит
   - Напряжение на коллекторе падает (становится близко к 0V)
   - Минус конденсатора (на базе) тоже падает → база "тянется вниз"

3. **Лавинное закрытие:**
   - База резко уходит вниз
   - Транзистор закрывается
   - LED гаснет

4. **Перезарядка:**
   - Конденсатор начинает заряжаться через резистор 100kΩ
   - Напряжение на базе медленно растёт
   - Когда достигает ~0.7V → транзистор снова открывается
   - **Цикл повторяется!**

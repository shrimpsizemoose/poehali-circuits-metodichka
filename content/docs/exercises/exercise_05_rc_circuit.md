## Теория

### Что такое конденсатор?

**Конденсатор** — это электронный компонент, который умеет **накапливать электрический заряд** (как маааааленькая перезаряжаемая батарейка).

**Принцип работы:**
```
     Две пластины (обкладки)
        │     │
   (+) ─┤     ├─ (-)
        │     │
       Диэлектрик
      (изолятор)

Между пластинами — изолятор (диэлектрик).
Угадайте что делает изолятор? Изолирует, правильно.
Ток не течёт напрямую, но заряд накапливается на пластинах.
```

**Ёмкость (C):**
Измеряется в **фарадах (F)**.
- 1 F — огромная ёмкость (для наших схем)
- 1 µF (микрофарад) = 0.000001 F — обычная ёмкость
- 1 nF (нанофарад) = 0.001 µF
- 1 pF (пикофарад) = 0.001 nF

В этом упражнении: **100 µF = 0.0001 F**

### Электролитический конденсатор

**Внешний вид:**
```
     ┌─────┐
     │  │  │
     │ ─┴─ │ ← Метка минуса (полоса)
     │     │
     └──┬──┘
        │
     Длинная ножка = (+)
     Короткая ножка = (-)
```

**ВАЖНО: ПОЛЯРНОСТЬ!**
- **Длинная ножка = плюс (+)**
- **Короткая ножка = минус (-)**
- На корпусе обычно есть **полоса со стороны минуса**

**Что будет при неправильной полярности:**
- Конденсатор нагреется
- Может **взорваться** (с хлопком и вонью)
- Электролит вытечет

> **Правило безопасности:** ВСЕГДА проверяйте полярность электролитических конденсаторов перед подключением!

### Заряд конденсатора

Когда конденсатор подключается к источнику напряжения через резистор:

```
     (+)
      │
     [R]  ← Резистор
      │
    ┌─┴─┐
    │ С │ Конденсатор
    └─┬─┘
      │
     (-)

Процесс:
1. Ток начинает течь
2. Конденсатор постепенно заряжается
3. Напряжение на конденсаторе растёт
4. Ток уменьшается
5. Конденсатор полностью заряжен → ток = 0
```

**График заряда:**
```
V на конденсаторе
  │
  │     ╱────────────
  │    ╱
  │   ╱
  │  ╱
  │ ╱
  └─────────────────────→ Время
    0  τ  2τ 3τ 4τ 5τ 6τ

τ (тау) = постоянная времени RC
```

### Разряд конденсатора

Когда заряженный конденсатор отключается от источника, он начинает **отдавать энергию** в цепь:

```
    [R]  ← Резистор
     │
   ┌─┴─┐
   │ С │ Заряженный конденсатор
   └─┬─┘
     │
    LED ← Светодиод горит от энергии конденсатора
     │
```

**График разряда:**
```
V на конденсаторе
  │
  │ ────╲
  │      ╲
  │       ╲
  │        ╲
  │         ╲
  └─────────────────────→ Время
    0    τ    2τ   3τ
```

### Постоянная времени RC

**Формула:**
```
τ = R × C

τ (тау) — постоянная времени (секунды)
R — сопротивление (Ом)
C — ёмкость (Фарады)
```

**Что это значит:**
- За время **τ** конденсатор зарядится на **~63%**
- За время **5τ** конденсатор зарядится на **~99%** (считается полностью)

**Расчёт для нашей схемы:**
```
R = 1kΩ = 1000 Ом
C = 100µF = 0.0001 Ф

τ = 1000 × 0.0001 = 0.1 секунды

Полный заряд: 5τ = 0.5 секунды
Полный разряд: 5τ = 0.5 секунды
```

Светодиод будет плавно гаснуть примерно **0.5 секунды**!

## Схема

### Текстовое описание
```
Батарея (+) → Кнопка → Резистор 1kΩ → Светодиод → Батарея (-)
Параллельно светодиоду: Конденсатор 100µF (соблюдая полярность!)
```

### ASCII-схема
```
      (+9V)
        │
       ┌┴┐
       │○│ Кнопка
       └┬┘
        │
      [1kΩ]
        │
        ├─────────┐
        │         │
       ╱│╲       ═╪═ (+)
      ╱ │ ╲      ═╪═ Конденсатор 100µF
     ────────     │  (-)
      LED         │
        │         │
        └────┬────┘
             │
            (-)
```

### Схема на макетке
```
Шина (+) ═══════════════════════════
                      │
   Ряд 5:  ●─[КНОПКА]─●
           │
          [1kΩ]
             │
   Ряд 10: ●─────────● ← Анод LED + (+) конденсатора
           │         │
          LED       CAP
           │         │
   Ряд 11: ●─────────● ← Катод LED + (-) конденсатора
              │
Шина (-) ═══════════════════════════
```

**Важно:**
- Анод светодиода и **плюс (+)** конденсатора в одном ряду
- Катод светодиода и **минус (-)** конденсатора в одном ряду

## Пошаговая инструкция

### Шаг 1: Подготовка
1. **Отключите батарейку**
2. Очистите макетку

### Шаг 2: Кнопка
1. Установите кнопку поперёк центральной канавки (как в упр. 2)
2. Провод от **шины (+)** к верхней ножке кнопки

### Шаг 3: Резистор
1. Вставьте резистор 1kΩ (коричневый-чёрный-красный):
   - Одна ножка к нижней ножке кнопки
   - Вторая в **ряд 10**

### Шаг 4: Светодиод
1. Вставьте светодиод:
   - **Анод** (длинная ножка) в **ряд 10** (с резистором)
   - **Катод** (короткая ножка) в **ряд 11**

### Шаг 5: Конденсатор (ВНИМАНИЕ: ПОЛЯРНОСТЬ!)
1. Найдите полярность конденсатора:
   - **Длинная ножка = (+)**
   - **Полоса на корпусе = (-)**
2. Вставьте конденсатор:
   - **Плюс (+)** (длинная ножка) в **ряд 10** (с анодом светодиода!)
   - **Минус (-)** (короткая ножка) в **ряд 11** (с катодом светодиода!)

> **КРИТИЧНО:** Плюс конденсатора к плюсу светодиода (анод), минус к минусу (катод)!

### Шаг 6: Замыкание на землю
1. Провод от **ряда 11** (катод + минус конденсатора) к **шине (-)**

### Шаг 7: Проверка
1. Подключите батарейку
2. **Нажмите кнопку:** светодиод загорается
3. **Отпустите кнопку:** светодиод плавно гаснет! ✨

## Что наблюдать

✓ **При нажатии кнопки:** светодиод загорается мгновенно
✓ **При удержании кнопки:** светодиод горит ярко
✓ **При отпускании:** светодиод плавно гаснет за ~0.5-1 секунду

**Что происходит:**
1. **Кнопка нажата:** Конденсатор заряжается через резистор, светодиод горит
2. **Кнопка отпущена:** Конденсатор разряжается через светодиод, питая его
3. **Конденсатор разряжен:** Светодиод гаснет

## Эксперименты

### Эксперимент 1: Разные резисторы

Измените резистор 1kΩ на другие номиналы:

| Резистор | Постоянная времени τ | Время гашения (~5τ) |
|----------|---------------------|-------------------|
| 220Ω | 0.022 с | 0.1 с (быстро) |
| 1kΩ | 0.1 с | 0.5 с (норма) |
| 10kΩ | 1 с | 5 с (медленно) |
| 100kΩ | 10 с | 50 с (очень медленно) |

**Вывод:** Больше резистор → медленнее гаснет.

### Эксперимент 2: Разные конденсаторы

Измените конденсатор 100µF на другие:

| Конденсатор | Постоянная времени τ (R=1kΩ) | Время гашения |
|-------------|---------------------------|--------------|
| 10µF | 0.01 с | 0.05 с (быстро) |
| 100µF | 0.1 с | 0.5 с (норма) |
| 1000µF | 1 с | 5 с (медленно) |

**Вывод:** Больше конденсатор → медленнее гаснет.

### Эксперимент 3: Экстремальные значения

Попробуйте:
- **Большой резистор + большой конденсатор:** 100kΩ + 1000µF = 100 секунд!
- Светодиод будет гаснуть несколько минут

### Эксперимент 4: Плавное включение

Переместите конденсатор параллельно кнопке:
```
      (+)
       │
    ┌──┴──┐
   CAP   BTN ← Конденсатор и кнопка параллельно
    └──┬──┘
      [R]
       │
      LED
       │
      (-)
```

**Результат:** При нажатии кнопки светодиод плавно **загорается**, а при отпускании мгновенно гаснет (обратное поведение!).

Вопрощающе закатите глаза и закиньте руки вверх, после чего трагично воскликните "ПОЧЕМУУУУУУУУУУ". После этого подумайте и постарайтесь понять, и правда, почему.

## Возможные проблемы

### Светодиод не гаснет плавно (гаснет сразу)

**Причина 1: Конденсатор не параллельно светодиоду**
- **Решение:** Убедитесь, что конденсатор подключён параллельно светодиоду (анод к аноду, катод к катоду)

**Причина 2: Слишком маленький конденсатор или резистор**
- **Решение:** Используйте 100µF и 1kΩ (или больше)

**Причина 3: Неисправный конденсатор**
- **Решение:** Попробуйте другой конденсатор

### Конденсатор греется

**Причина:** Неправильная полярность!
- **Решение:** **НЕМЕДЛЕННО отключите питание!** Переверните конденсатор правильно.

### Светодиод вообще не загорается

**Причина 1: Конденсатор закорачивает светодиод**
- Проверьте схему: конденсатор должен быть **параллельно** светодиоду, а не вместо него

**Причина 2: Неправильная полярность светодиода или конденсатора**
- **Решение:** Проверьте полярность обоих компонентов

### Очень долго гаснет (десятки секунд)

**Причина:** Слишком большое сопротивление или ёмкость
- Это не проблема — это эксперимент! Попробуйте меньшие номиналы.

## Применение RC-цепей

RC-цепи используются везде:

- **Задержки:** светодиод гаснет не сразу (как в этом упражнении)
- **Фильтры:** сглаживание пульсаций в блоках питания
- **Таймеры:** создание временных интервалов (например, в микросхеме 555)
- **Генераторы:** создание колебаний (следующие упражнения!)
- **Плавные переходы:** в аудио, освещении, анимации

⚡ Тест отображения ASCII-схем

Эта страница показывает правильное отображение ASCII-схем с моноширинным шрифтом.

Сравнение

❌ Неправильно (пропорциональный шрифт)

    +9V
     │
  [220Ω]
     │
    ╱│╲
   ╱ │ ╲  LED
  ────────
     │
    GND

✅ Правильно (моноширинный шрифт)

    +9V
     │
  [220Ω]
     │
    ╱│╲
   ╱ │ ╲  LED
  ────────
     │
    GND

Примеры схем

1. Простая схема с LED

        (+9V)
         │
      [220Ω]  ← Резистор
         │
        ╱│╲
       ╱ │ ╲  ← Светодиод
      ────────
         │
        GND

2. Схема с кнопкой

      (+9V)
        │
       ┌┴┐
       │○│ Кнопка
       └┬┘
        │
      [220Ω]
        │
       LED
        │
       GND

3. Транзистор как ключ

        (+9V)
         │
      [220Ω]
         │
        LED
         │
         C
         │
    ┌────┴────┐
    │    Q    │  Транзистор
  B │         │ E
    └────┬────┘
         │         │
         │         └──→ (-)
         │
      [10kΩ]
         │
        BTN
         │
        (+)

4. Мультивибратор

         (+9V)
           │
      ┌────┴────┐
      │         │
    [1kΩ]    [1kΩ]
      │         │
     LED1      LED2
      │         │
      C1        C2
      │         │
     Q1        Q2
      │         │
      E1────────E2
           │
          (-)

5. Делитель напряжения

     (+9V)
       │
    ┌──┴──┐
    │ 10kΩ│ R1
    └──┬──┘
       ├───→ V_out
    ┌──┴──┐
    │ 10kΩ│ R2
    └──┬──┘
       │
      GND

Текстовые таблицы

| Компонент | Значение | Назначение      |
|-----------|----------|-----------------|
| R1        | 220Ω     | Для LED         |
| R2        | 10kΩ     | База транзистора|
| C1        | 10µF     | Времязадающая   |

Псевдографика

┌───────────────────────────────┐
│  Макетная плата (breadboard)  │
├───────────────────────────────┤
│  ● ● ● ● ●   ● ● ● ● ●       │
│  ● ● ● ● ●   ● ● ● ● ●       │
│  ● ● ● ● ●   ● ● ● ● ●       │
├───────────────────────────────┤
│  ═══════════  ← Шина (+)      │
│  ═══════════  ← Шина (-)      │
└───────────────────────────────┘

Проверка выравнивания

Все символы должны быть выровнены по вертикали:

|  |  |
│  │  │
║  ║  ║
┃  ┃  ┃
█  █  █
▓  ▓  ▓

Совет: Если схемы "разъезжаются", убедитесь что используется моноширинный шрифт и все символы имеют одинаковую ширину.
